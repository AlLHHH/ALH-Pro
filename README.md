# ALH Pro

图片、视频、音频的本地增强工具。所有处理在本机完成,不上传文件、不收集数据,断网可用。

当前版本 **v1.4.11**。官网:https://alhpro.cn

功能包括图片超分、AI 抠图、视频超分、视频补帧、视频去除重复帧、音频分离与增强。

## 关于「去除重复帧」

这一项是帧级去重,针对动画素材的作画节奏。

动画常用「一拍二」「一拍三」的方式作画:一个画面连续占 2 帧或 3 帧。这些重复的帧对观看没有作用,但会让补帧引擎把它们当成连续动作,插出多余的中间帧,画面反而变糊、出现抖动。ALH Pro 的做法是先把重复的保持帧删掉,还原出素材真实的内容帧率,再按内容帧率做补帧,最后按原时长输出。

所以这里的「去重」指删掉动画里重复的画面帧,与平台上判定搬运、规避重复检测的那类处理没有关系。软件不做这类判断,也没有相关功能。

三种模式:智能检测(自动估拍数)、动漫模式(指定去一拍二 / 一拍三 / 混合)、手动模式(内容帧率采样、帧差加 SSIM、重复帧检测、画面变化阈值)。只删确认为重复的作画帧,口型、眨眼、微动不删;没有重复帧的素材原样通过。

## 功能

### 图片放大

- 超分模型:动漫插画用 waifu2x,实拍照片用 Real-ESRGAN,倍率 1x(只增强不放大)到 4x
- 降噪三档,照片模式带预处理降噪
- 后处理:去雾、减少杂色、锐化、钝化蒙版、保留细节、去模糊、边缘增强、边缘抗锯齿
- 批量处理,输出 JPG / PNG,多图自动分文件夹

### AI 抠图

- 六款模型:U²-Net(通用、轻量)、ISNet(精细边缘、动漫)、BiRefNet(高精度,完整版附带)
- 前景阈值、背景阈值、边缘羽化、边缘增强、边缘清理
- 棋盘格预览透明区域,按住可对比原图

### 视频处理

- 超分:实拍用 Real-ESRGAN,动漫用 Real-CUGAN,1x 修复到 4x
- 补帧:Real-RIFE,模型 v4.13 与 v4.6,输出帧率等于原帧率乘倍率
- 去除重复帧:见上一节
- 视频降噪、后处理、光流调整、转场识别与转场阈值
- 批量管理:完成置灰、重新激活、拖拽排序、只处理选中项、完成后删除源文件
- 输出 MP4 / MKV,H.264 或 H.265,码率可调,可静音导出

### 音频处理

- 升采样:8k / 16k / 22k / 32k 的低采样率素材补到 48kHz
- 增强:人声与伴奏分别优化后重混
- 分离:基于 Demucs,可提取人声、去人声、分离导出两轨,或按自定义组合多轨输出并单独调整音量
- 降噪三档、响度归一、低切、清晰增强,输出 WAV / FLAC / MP3,带波形预览与首尾裁剪

### 运行保障

- 按本机显存、内存、CPU 自动定档,分块与批大小自适应,处理时降低进程优先级,可设置降温休息间隔
- 启动时检测显卡,引擎不兼容时自动切到 DirectML 路线,结果不受影响
- 显卡驱动过旧导致硬件编码不可用时,会自动换用旧版编码器;仍不可用则在开始前说明原因,不会静默跑成 CPU 编码

## 系统要求

- Windows 10 / 11,x64
- 无独立显卡也能用,会自动降级到 CPU 处理,速度慢很多
- 视频处理建议独立显卡加 16 GB 内存,临时目录预留足够空间(4K 素材建议 50 GB 以上)

| RTX 40 / 30 系 | 显卡 | 显卡 | 显卡 | 显卡 | CPU |
| RTX 50 系 | 显卡(部分组合自动换稳定引擎) | 同上 | 同上 | 显卡 | CPU |
| RTX 20 系 | 可用,视驱动可能降级 | 可用 | 显卡 | 显卡 | CPU |
| GTX 16 系 | 显卡 | 显卡 | 显卡 | 显卡 | CPU |
| GTX 10 系 | 可用,视驱动可能降级 | 可用 | 显卡 | 显卡 | CPU |
| AMD 较新独显 | 可用,视驱动可能降级 | 可用 | 可用 | 可用 | CPU |

抠图固定用 CPU,避免占满显卡拖慢整机。音频升采样目前也走 CPU。

## 从源码构建

```
dotnet build ImgUpscalerUI/ImgUpscalerUI.csproj -c Release -p:Platform=x64
```

需要 .NET 8 SDK 与 Windows 10/11 x64。构建产物依赖程序目录下的 `engines\`(waifu2x、realesrgan、realcugan、rife、ffmpeg、rembg 等),引擎与模型不随源码提供,需自行按 `THIRD_PARTY_NOTICES.txt` 里的项目与版本获取。
