# 模型包打包说明(models_v1.0.zip)

## 用途

ALH Pro 主程序包(安装版)不含抠图模型(模型 1.65GB,避免安装包超 GitHub Release 2GB 上限)。
模型包独立为 GitHub Release 附件,两种安装方式:

1. **安装时勾选**(推荐):安装程序「选择附加任务」页勾选「下载并安装模型包(来自 GitHub)」,
   安装完成自动下载并解压到 `程序目录\engines\rembg\`;
2. **手动解压**:下载 `models_v1.0.zip`,解压到 `ALH Pro 程序目录\engines\rembg\` 文件夹,
   得到该目录下 6 个 .onnx(与安装器自动解压位置一致)。

## 包内结构(扁平:解压即 6 个模型 + 说明)

```
birefnet.onnx              927.6 MB  (BiRefNet 完整版,复杂背景)
birefnet-lite.onnx         213.6 MB  (BiRefNet 高精度,默认推荐)
isnet-anime.onnx           167.9 MB  (ISNet 动漫)
isnet-general-use.onnx     170.4 MB  (ISNet 精细边缘)
u2net.onnx                 167.8 MB  (U²-Net 通用)
u2netp.onnx                  4.4 MB  (U²-Net 轻量)
README.txt                          (安装说明)
```

模型必须放在 `程序目录\engines\rembg\` 下(软件递归扫描该目录,子目录亦可)。

## 打包命令(在仓库根执行)

```powershell
# 1) 准备目录:6 个 .onnx + README.txt
# 2) 用系统自带 tar 打包(扁平,无 2GB 限制)
tar -a -c -f 打包工具\models_v1.0.zip -C <模型目录> .
# <模型目录> 内直接是 6 个 .onnx 与 README.txt;不要把目录本身套进去
```

> 不要用 `Compress-Archive`(大文件慢,且中文路径易错)。

## 模型许可

6 个模型均来自各自上游开源仓库:
- U²-Net / ISNet:Apache-2.0(xuebinqin/DIS)
- BiRefNet:MIT(ZhengPeng7/BiRefNet)
- 转换工具 rembg:MIT(Daniel Gatis)

详见软件内 THIRD_PARTY_NOTICES.txt 第 5-8 条。

## 发布时

1. 上传 `models_v1.0.zip` 到 GitHub Release 附件(单文件 <2GB 限制);
2. 更新 `installer.iss` 中 `#define ModelsUrl` 为真实直链(形如
   `https://github.com/<owner>/<repo>/releases/download/<tag>/models_v1.0.zip`);
3. 主程序包 `ALHPro_v1.0_Setup.exe` 同样上传 Release。
