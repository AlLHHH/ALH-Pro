【ALH Pro 抠图模型包 — 安装说明(必看)】
=========================================

这个 zip 里是 6 个 AI 抠图模型(共约 1.4GB)。装好后,
软件「AI 抠图」页才能用;其它功能(图片放大/视频/音频)不受影响。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
怎么装(二选一)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式一(推荐):安装软件时,在「选择附加任务」页
　　　　　　勾选「下载并安装模型包(来自 GitHub)」,
　　　　　　安装程序会自动下载并放好。

方式二(手动,下载失败时用这个):
 1) 找到 ALH Pro 的程序目录(不是桌面图标,是软件安装位置):
    　默认位置:C:\Users\你的用户名\AppData\Local\Programs\ALH Pro
    　或:右键桌面「ALH Pro」图标 → 打开文件所在位置
 2) 在程序目录里进入 engines 文件夹(没有就建一个),
    再进入 rembg 文件夹(没有就建一个)。
 3) 把本 zip【解压】到 rembg 文件夹里,得到:
    　程序目录\engines\rembg\
    　　　birefnet-lite.onnx
    　　　birefnet.onnx
    　　　isnet-general-use.onnx
    　　　isnet-anime.onnx
    　　　u2net.onnx
    　　　u2netp.onnx
    (6 个 .onnx 文件直接放在 rembg 里;不要解压缩成
     一个"models_v1.0"文件夹再放进去——多套一层或
     少放一层都会找不到)

 4) 怎么确认装好了:打开 ALH Pro → AI 抠图页,
    页面左上角【没有】黄色"⚠ 未找到抠图模型"提示 = 成功。

常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 我在安装器里勾了下载但失败了/卡住了?
A: 网络原因(1.4GB,国内直连 GitHub 容易断)。别着急,
   安装通常已经完成——用上面的「手动方式」补装即可,
   建议用浏览器/迅雷/IDM 下载(支持断点续传,更快更稳)。

Q: 解压后软件还是提示「未找到抠图模型」?
A: 检查两点:① 是不是解压到了一个多套一层的文件夹
   (比如 程序目录\engines\rembg\models_v1.0\{onnx})——
   删掉多余的层级;② 文件是否完整(6 个文件一个都不能少)。

Q: 下载很慢/下不动,有没有别的下载渠道?
A: GitHub 页面点击 Download 时可用镜像加速(如
   ghproxy),或找 ALH Pro 社区(软件内「ALH Pro 社区」)
   群友要一份。注意:解压后必须放在 engines\rembg 里,
   放在哪都行,就是别把整个文件夹拷错位置。
