## 一、软件概述

**软件全称**:ALH Pro(图片/视频/音频 AI 增强工具)
**软件简称**:ALH Pro
**版本号**:V1.3.0
**运行环境**:Windows 10/11(x64),.NET 8,Windows App SDK(WinUI 3)
**软件类型**:桌面应用(单机本地运行)

**功能定位**:
ALH Pro 是一款面向普通用户的**本地 AI 图像/视频/音频处理工具**,集成多个开源 AI 引擎与神经网络模型,提供**图片放大、AI 抠图、视频超分、视频补帧、视频去重、音频分离、音频增强、音频升采样**等功能。所有处理均在用户本机完成,**不联网上传、不收集用户数据**。界面全中文,无需复杂参数即可上手。

**开发环境**:Visual Studio 2022,C# 12,.NET 8,WinUI 3
**主要依赖**:Ffmpeg、waifu2x-ncnn-vulkan、realesrgan-ncnn-vulkan、rife-ncnn-vulkan、ONNX Runtime、U²-Net/ISNet/BiRefNet、Demucs、LavaSR 等开源组件(详见《第三方组件许可声明》)。

## 二、总体架构

软件采用 **WinUI 3 桌面应用**架构,主窗口内以左侧导航 + 右侧功能区组织各功能模块:

```
┌──────────────┬──────────────────────────────┐
│  左侧导航栏   │        主工作区(功能页)          │
│  · 图片放大   │   · UpscaleView(图片超分)       │
│  · AI 抠图    │   · CutoutView(AI 抠图)        │
│  · 视频处理   │   · VideoView(视频处理)         │
│  · 音频处理   │   · AudioView(音频处理)         │
│  · 使用教程   │   · TutorialView(图文教程)      │
│  · 设置 / 关于 │   · MainPage(主控/导航调度)     │
└──────────────┴──────────────────────────────┘
```

- **界面层**:各功能页(XAML)负责交互与展示
- **服务层**:`VideoService` / `EngineService` / `UpscaleService` / `AudioService` / `CutoutService` 等负责业务逻辑,统一调度底层引擎
- **引擎层**:以独立进程方式调用 ffmpeg、waifu2x-ncnn-vulkan、realesrgan-ncnn-vulkan、rife-ncnn-vulkan;推理用 ONNX Runtime(DirectML/CPU)
- **配置层**:`AppSettings` / `SafeRender` 管理设备、显存/内存墙、休息降温等安全参数

## 三、功能模块详述

### 3.1 图片放大(图片超分)
**功能描述**:对图片进行 AI 放大(超分辨率),支持动漫与写实两类模型,1x~4x 可变。

- **模型**:动漫插画(w aifu2x-cunet)、写实照片(Real-ESRGAN x4plus)、动漫视频模型(animevideov3)
- **倍率**:1x(只提清晰不变大)~ 2x ~ 4x
- **降噪**:无 / 中 / 强 / 照片模式预处理降噪
- **后处理**:去噪、减少杂色、锐化、清晰、钝化蒙版、保留细节、细节增强、去模糊、边缘增强、边缘抗锯齿等 10 余种增强
- **批量**:多图批量处理,输出 JPG/PNG,自动分子文件夹

### 3.2 AI 抠图(移除背景)
**功能描述**:一键移除图片背景,支持抠图模型选择与前后景调整。

- **模型**:U²-Net(通用/轻量)、ISNet(精细边缘/动漫)、BiRefNet(高精度/完整版),共 6 款
- **控制**:前景/背景阈值、边缘羽化、边缘增强、边缘清理
- **预览**:彩色预览(原图 × 蒙版,棋盘格=透明区域),按住查看原图

### 3.3 视频处理
**功能描述**:视频的超分/补帧/去重/增强一站式处理,输出 MP4/MKV。

- **视频超分**:经典动漫(waifu2x)/ 写实通用(Real-ESRGAN),1x 超分 ~ 4x 或自定义分辨率
- **补帧(RIFE)**:v4.13 / v4.6 / v4.26 / 动漫 / 高清 / 超高清 / 经典兼容,输出帧率 = 原帧率 × 倍率
- **去除重复帧(动画常选)**:智能检测自动估节奏 / 动漫模式 / 手动模式(内容帧率采样、帧差+SSIM、重复帧检测、画面变化阈值),支持相位自动对齐
- **去重后规整**:输出帧率 = 内容帧率 × 补帧倍率,时长 = 源时长,尾帧恒保留
- **视频降噪**(非局部均值)、后处理、果冻修复、光流调整、转场识别
- **批量管理**:完成置灰、重新激活、拖拽排序、只处理选中、完成后自动删除
- **输出**:MP4 / MKV;H.264 / H.265;码率可调;静音导出;HDR/广色域源自动转 BT.709 SDR

### 3.4 音频处理
**功能描述**:音频分离、增强、升采样率,支持波形预览与首尾裁剪。

- **AI 升采样率**:电话/老录音等低采样率源(8k/16k/22k/32k)→ 48kHz,AI 补全高频
- **增强**:人声/伴奏分别优化后重混,咬字更清晰、层次更好
- **AI 分离(Demucs)**:提取人声 / 去人声(卡拉OK)/ 分离导出两文件 / 自定义组合(多轨同时输出 + 各自音量 0~200%)
- **后处理**:降噪、响度归一、低切、清晰增强;输出 WAV / FLAC / MP3;波形预览 + 首尾裁剪

### 3.5 安全渲染与设备适配
- **安全渲染**:显存/内存/CPU 墙按本机配置自动调节;分块/批大小自适应;处理时降低进程优先级;设备降温休息(可调间隔)
- **设备自检**:启动自动检测 GPU;有独立显卡且引擎兼容 → 自动启用;不兼容时自动改走稳定路线(DirectML),输出结果不受影响
- **RTX 50 系(Blackwell)**:已自动适配 —— 图片/视频超分与补帧自动选择稳定引擎,界面明确提示,无需设置
- **兼容模式/弱设备**:弱设备(无 GPU、核显、显存<6G、内存<8G、核数≤4)黄字提醒建议开启;自动降分块/批大小防爆显存

### 3.6 其它功能
- **使用教程**:图文操作说明,每个功能怎么用、参数什么时候调、常见问题处理
- **设置**:计算设备选择、临时文件位置、显存/内存上限、CPU 线程量、系统流畅优先、降温休息、温度墙、诊断日志导出
- **更新检查**:启动后台静默检查 GitHub 是否有新版本;有新版才提示条
- **设备自检报告**:设置页常驻显示「计算设备 / 推荐设备 / 显存 / 内存 / 驱动 / DirectML / 功能自检 / 引擎模型」
- **诊断包**:一键导出日志 + 设备信息 + 设置,便于向作者反馈问题
- **广告说明**:软件为免费软件,通过左栏广告位展示合作方广告(可关闭、可彻底关闭、不收集个人信息)

## 四、软件特色

1. **全本地运行**:所有 AI 处理均在用户本机完成,不上传、不收集任何用户数据,隐私安全。
2. **中文界面**:全中文交互,无需英文基础,零门槛上手。
3. **多引擎集成**:图片(waifu2x/Real-ESRGAN)、视频(RIFE 补帧)、音频(Demucs/LavaSR),覆盖主流 AI 增强场景。
4. **自动适配显卡**:启动自检 GPU,自动选择稳定引擎(含 RTX 50 系 Blackwell 适配),弱设备自动降级,无需手动调参。
5. **成果导向**:处理完成即时显示输出大小/帧率/分辨,批量处理 + 一键打开输出文件夹。
