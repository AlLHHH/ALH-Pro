隐私说明

适用软件版本:v1.3.6 及以后 · 本页内容与软件内「关于 → 隐私政策」指向同一套事实,并已把三项联网行为全部列全

结论: 你的图片、视频、音频处理全部在你自己的电脑上完成,不上传到任何服务器。 软件不需要注册账号,不收集个人信息,不做使用行为统计,也没有云端记录。 软件里只有三处会联网 —— 检查更新、拉取广告素材、拉取界面提示文案 —— 它们既不涉及你的文件,也不涉及你的设备信息,任何一处失败都不影响任何功能,全部有内置兜底。

一、软件不会做的事

以下这些都是明确不做的,不是“尽量不做”:

  • 不上传你的文件内容:图片、视频、音频,以及处理过程中产生的中间帧、临时文件,全部留在本机。
  • 不上传文件名、不上传文件路径:软件不会把你处理了什么文件、文件放在哪个目录发出去。
  • 不上传画面或音频数据:不会有任何“抽帧上传”“预览上传”“云端加速”之类的事情。
  • 不上传设备信息:显卡型号、显存、CPU、内存、驱动版本、系统版本这些只在本机用于自动选择计算设备与生成自检报告,不会发出去。
  • 不做使用行为统计:不收集你点了什么、处理了多少次、用了哪些模型,没有埋点、没有第三方统计 SDK。
  • 没有账号体系:不注册、不登录、不绑定手机号/邮箱,因此也没有云端历史记录。

二、会自动发生的联网行为

这三项都不传输你的个人信息、设备信息或文件信息。它们的共同点是:只从公开仓库取回公开文本或公开图片, 请求走 HTTPS,请求头里只有一个固定的程序标识与软件版本号(形如 ALHPro/1.3.6)—— 这是 HTTP 请求本身要求的头部,不含文件名、路径、画面或机型。

1. 更新检查

  • 什么时候:启动软件时自动检查一次(检测到新版本会提示你;不自动下载、不自动安装)。
  • 请求到哪里: api.github.com(GitHub 官方接口); 直连不通时会改用镜像 gh-proxy.com 转发同一个接口。
  • 传输什么:只读取该项目的“最新发布版本号”这个公开信息。
  • 不传输什么:不传设备信息、不传文件信息,也不上传任何本地数据。
  • 失败会怎样:静默忽略,不做任何提示,软件照常使用。

2. 广告素材拉取

  • 什么时候:启动软件时、以及运行期间定时刷新(用于更新界面下方广告位的文案与图片)。
  • 请求到哪里(按顺序尝试,任一成功即停): cdn.jsdelivr.net(公共 CDN 镜像)、 gh-proxy.com、 ghproxy.net、 raw.githubusercontent.com; 请求的是公开仓库里的 ad1.json、ad2.json… 以及对应的广告图片。
  • 传输什么:只取回公开的广告文案与图片。广告不含个性化推荐, 不读取你的设备标识、不读取你的处理记录,也不向广告方回传任何数据。
  • 失败会怎样:静默忽略,广告位不显示,功能完全不受影响。
  • 不想看广告:点广告卡右上角「✕」可隐藏该条;或在「设置 → 本次运行不显示广告」中勾选,本次运行生效,重启后恢复显示。目前没有永久关闭开关。

3. 界面提示文案拉取

  • 什么时候:启动软件时、以及运行期间每约 10 分钟刷新一次(提示条本身每 30 秒在本地轮换,轮换不联网)。
  • 请求到哪里:与上一条相同的一组地址,请求的是公开仓库里的 hint1.json、hint2.json… 这些纯文本提示文件。
  • 传输什么:只取回公开的提示文案(可能包含一条可点击的官方链接)。
  • 不传输什么:同样是只读拉取,不回传你的任何信息。
  • 失败会怎样:静默忽略,提示条显示软件内置的默认文案,功能完全不受影响。

三项联网行为速查

行为触发时机目标地址传输内容失败后果
检查更新 启动时 api.github.com(镜像:gh-proxy.com) 只读取公开的最新版本号 静默忽略,可用
广告素材拉取 启动时 + 运行中定时刷新 cdn.jsdelivr.net、gh-proxy.com、ghproxy.net、raw.githubusercontent.com 只取回公开的广告文案与图片 隐藏广告位,可用
界面提示文案拉取 启动时 + 约每 10 分钟 同上四个地址 只取回公开的提示文本 显示内置默认提示,可用

结论:三项全部是“只读地取回公开内容”,没有任何一项会把你的数据发出去; 三项全部失败(例如断网、内网、GitHub 不可达)时,软件的功能与画质完全不受影响。

禁止软件联网的方法: 可以在 Windows 防火墙或安全软件里禁止 ALHPro.exe 联网。禁止后软件仍可正常处理素材, 只是不会提示新版本、广告位与提示条使用内置内容。

三、只有你主动点击 / 主动选择时才会发生的联网

  • 打开问卷或反馈入口:只有在你自己点击时才会用浏览器打开对应网页(例如问卷平台),该页面由第三方按它自己的隐私政策处理数据; 软件不代你提交、不读取结果。
  • 点“去下载 / 网盘下载 / 查看更新详情”:用浏览器打开 GitHub 发布页或百度网盘,同样是你的主动操作,之后发生的一切由该网站的规则决定。
  • 安装时勾选“下载并安装模型包”,或你自己下载模型包 / 安装包:这是下载行为,会从 GitHub 获取文件;不勾选就完全不联网。

四、软件在本机产生、但不会外发的文件

  • 设置与预设:保存在 %LOCALAPPDATA% 下的本地文件,记录你选择的参数;
  • 日志:记录运行过程与报错,用于你自己排查问题,保存在本机;
  • 临时文件:视频处理的中间帧等,处理完毕后自动清理,并在启动时清理历史残留;
  • 自检报告:启动时检测显卡、显存、内存、引擎与模型的可用性,结果只显示在界面上并保存在本机;
  • 诊断包(你主动导出才会生成):包含本机日志、设备信息与设置,只保存在本机。 软件不会自动发送它;发不发、发给谁,完全由你决定。

五、第三方与开源组件

  • 开源引擎与模型:waifu2x、Real-ESRGAN、RIFE、U²-Net、ISNet、BiRefNet、FFmpeg、ONNX Runtime、Demucs、LavaSR 等 全部以本地进程 / 本地库方式调用,不会向它们的作者或任何第三方传输你的数据。它们各自的许可与版权见 开源许可与致谢。
  • 广告素材与提示文案的托管:内容托管在公开代码仓库及其公共镜像 / CDN 上(上面列出的四个域名)。 这些服务在技术上会看到请求来自哪台机器(IP 与请求头),这是任何网络请求都无法避免的;我们能控制的是:请求里不含你的文件信息、设备信息或使用记录。
  • 问卷平台:仅在你点击时打开,数据由该平台按自身政策处理,与本软件无关。

六、关于本站

  • 本站是纯静态页面(只有 HTML / CSS 和一点本地 JS),不加载任何第三方脚本、统计代码、在线字体或境外 CDN 资源;
  • 本站不设置 Cookie、不使用本地存储记录你,页面脚本不写入任何标识;
  • 服务器(主机商)会按行业惯例记录基础访问日志(如 IP、时间、浏览器标识),用于运维与安全防护,本站不将这些日志用于统计画像或广告投放。

七、变更与联系

  • 软件功能变化若涉及联网行为,我们会在版本更新说明中写明,并同步更新本页与软件内的隐私政策;
  • 你随时可以卸载软件;卸载后本机不再有该软件的数据(你可以自行删除 %LOCALAPPDATA% 下的设置与日志目录);
  • 关于本说明的疑问,可通过软件内「关于 → 联系方式」反馈。
