常见问题

常见问题 · 点标题看答案。 遇到问题建议优先去软件左下角的「ALH Pro 社区」反馈,提问时带上版本号、显卡与日志会快很多。

下载与安装

下载很慢、或者中途断了怎么办?

按顺序试,一般三步内能解决:

  1. 用百度网盘。完整版约 2.0 GB、含全部模型,网盘 分享名「ALH Pro」,提取码 6eym。
  2. 给 GitHub 链接加加速前缀。例如 https://gh-proxy.com/ + 原始下载链接,免费、不用注册;还能换 ghproxy.net、ghproxy.com。
  3. 错峰下载。清早或深夜通常更稳,大文件支持断点续传。
双击安装包后没反应,是卡死了吗?

多半不是。安装包很大(完整版约 2.0 GB),Windows 安全软件首次会完整扫描,界面晚一点出现是正常的,等 1~2 分钟即可。

等几分钟仍没有窗口,可以:①在任务管理器看有没有安装程序在占 CPU / 磁盘;②把安装包复制到本地非系统盘再试;③重新下一次(多半是没下完整),或换另一条渠道的文件。

杀毒软件报毒 / 提示“未知发布者”,怎么办?

事实是:安装包没有购买商业代码签名证书,所以 Windows 与部分安全软件会提示“未知发布者”,或给出拦截 / 误报。这在未签名软件里很常见。

建议顺序:

  1. 确认是官方渠道的文件(文件名与大小对得上);
  2. 在安全软件里选“允许 / 信任 / 加入白名单”,或把程序目录加进排除项;
  3. 文件被删或隔离,先恢复并信任;反复被删,就把报毒名称与截图发到「ALH Pro 社区」。

只从官方渠道下载(GitHub Releases 与作者百度网盘)。第三方下载站或“绿色版”的安装包可能被重新打包,那种报毒就不能忽略了。

需要先装 .NET 吗?提示缺少运行库怎么办?

正常不需要。安装包是自包含的(.NET 8 已打进包里),不用另装 .NET,也不用 Visual C++ 运行库。

仍提示缺运行库,按顺序排查:

  1. 确认系统是 64 位 Windows 10(1809 及以上)或 Windows 11;更旧的系统装不上。
  2. 确认安装包完整(大小对得上),没下完整会出现解压 / 加载失败。
  3. 个别系统组件缺失时,到微软官网装 .NET 8 Desktop Runtime(x64) 再启动软件。
  4. 仍不行:导出「设置 → 诊断日志」发给我们,日志里通常能直接看出原因。
能装到别的盘吗?需要管理员权限吗?

默认装到当前用户目录 C:\Users\你的用户名\AppData\Local\Programs\ALH Pro,不需要管理员权限。

向导里可以改成别的目录;选 Program Files 时安装程序会请求管理员权限。装在非系统盘也可以,不影响功能。

支持 32 位系统、Windows 7、Mac 或手机(Android)吗?

ALH Pro 目前是 Windows 10 / 11 的 64 位(x64)桌面程序:32 位 Windows、Windows 7 及更早系统、macOS、Linux、iOS 都不能运行。

手机版敬请期待。目前只有 Windows 桌面版,手机 / 平板暂时用不了,还没有可下载的安装包(也没有 APK);做好之后会在下载页公布。

怎么升级?需要先卸载旧版、重新下模型吗?

不用卸载,也不用重装模型:直接下新安装包覆盖安装即可,引擎、模型与设置原样保留。

设置、预设、处理记录在 %LOCALAPPDATA%,覆盖安装不会动它们。

例外:若某版调整了后处理参数的机理,旧预设里的数值含义可能变化,更新说明里会专门提醒(见 更新日志)。

启动时软件自动检测 GPU:有独显且引擎兼容就自动启用;不兼容会自动走稳定路线,结果不受影响,只是速度有差别。走哪条路看页面上方的设备提示。

RTX 50 系为什么会被提示走了“兼容路线”?

50 系较新,部分内置引擎(基于 ncnn-Vulkan)在早期驱动上不完全兼容。软件会自动适配: 检测到 50 系就改用 ONNX / DirectML 稳定路线,显卡仍参与加速(不是退回纯 CPU),结果不受影响,页面上会有提示。

从 v1.3.5 起补帧引擎已用新版 ncnn 重编,50 系不必再等驱动修复。

提示“驱动偏旧 / 改走兼容路线”,一定要更新驱动吗?

不是必须,但更新显卡驱动后重启软件,通常能恢复完整的 GPU 加速。老驱动(2021 年以前)上引擎可能起不来,软件会自动降级(慢但稳)。

内置的视频编码器(NVENC)也需要较新的 NVIDIA 驱动,驱动过旧时软件会改用 CPU 软编码并提示你。

处理很慢,正常吗?

先看这几条最常见的“慢”:

  • 是不是在用 CPU?CPU 比 GPU 慢几倍到十几倍。看页面上方的设备提示与日志里的计算设备。
  • 倍率是不是太高?4x 超分 / 8x 以上补帧的耗时与占用成倍上升。老电脑先试 1x 超分、2x 补帧。
  • 模型是不是“质量优先”?同样 1080p 超分:轻量模型约 0.25 秒/帧,x4plus 约 15 秒/帧。
  • 素材是不是 4K / 高帧率?4K 补帧单帧耗时约是 1080p 的 3 倍多。
  • 音频分离本身慢。优先用显卡(DirectML);无显卡时用 CPU,一首歌几分钟到十几分钟。

状态栏会显示进度与剩余时间估计,建议先用一小段样片试跑,确认参数和耗时再整段处理。

大概多久能跑完一段视频?有参考数据吗?

以下是本机实测的量级,测试机为 RTX 4060 Laptop:

  • 1080p 超分:动漫常用模型约 0.25 秒/帧(4x 约 0.30 秒/帧),轻量通用模型 4x 约 0.46 秒/帧,x4plus 约 15 秒/帧;
  • 1080p 补帧:约 0.08 秒/输出帧;2160p(4K)约 0.28 秒/输出帧;
  • 一个真实作业:1080p、72 帧(约 2.4 秒),4 倍补帧 + 2 倍超分,全程约 53.7 秒。

这些是本机实测数字,不是承诺;换显卡、模型或素材后差别可能较大,以软件内显示的预计剩余时间为准。

功能与效果

AI 抠图提示“模型未安装”,怎么装?

安装包不含抠图模型(约 1.4 GB),要单独补。两种办法:

  1. 重新运行安装包,在「选择附加任务」页勾选「下载并安装模型包」;
  2. 或手动下载 models_v1.0.zip,把里面 6 个 .onnx 文件直接解压到 程序目录\engines\rembg\(不要再套一层文件夹)。

装好的标志:AI 抠图页左上角的黄色提示消失。完整步骤见 使用教程 · 抠图模型安装;嫌麻烦就用完整版(含全部模型)。

放大后图发糊 / 变得像画出来的,是哪里设错了?
  • 动漫图发糊 → 算法可能选成了 Real-ESRGAN;动漫 / 插画该用 waifu2x。
  • 照片显得很“画” → 大概用了 waifu2x;照片 / 实拍该用 Real-ESRGAN。
  • 图发虚、有马赛克 → 倍率可能偏高或引擎选错;先试 1x 超分(只变清晰、不放大)。
  • 细节被磨掉了 → 降噪太强。干净素材用「不降噪 / 弱」。
抠图边缘粗糙 / 缺了一块,怎么调?
  • 提高抠图页的「边缘增强」,或换成 ISNet 精细边缘(人像 / 产品)、ISNet 动漫(动漫插画); (它管的是蒙版边缘,和视频页那个同名的不是一回事,见 下面这条);
  • 背景与主体颜色接近时,降低前景阈值、提高背景阈值,或勾「自适应阈值」;
  • 抠毛发、半透明边缘时调高「边缘羽化」;
  • 边缘有碎点杂色时开启「边缘清理」。

小提示:先用一张图调好参数,再点批量,避免整批返工。

视频的「边缘增强」是干什么的?和抠图的「边缘增强」是同一个功能吗?

不是同一个功能,只是名字一样:一个在视频页(超分之后处理画面),一个在AI 抠图页(抠图之后处理蒙版)。

  • 视频页「边缘增强」:只加强明确边缘 —— 先用阈值把平坦区与噪点保护起来,再提高线条与轮廓的对比。 默认值随所选超分模型给(animevideov3 = 30,其它模型 = 60);画面发“锐”就调低或关掉。
  • AI 抠图页「边缘增强」:处理的是蒙版边缘 —— 去背景后主体轮廓的毛糙、白边、碎点,不改变画面本身的锐度。

怎么选:画面线条、轮廓不够利落 → 调视频页那个;抠出来的人或物边上毛毛的、有白边 → 调抠图页那个。

展开细节见 使用教程 · 视频处理 可选后处理。

补帧之后画面有“果冻”扭曲 / 动作反而怪?
  • 勾上果冻修复,给快速运动处盖一层真实运动模糊,观感更自然;
  • 调光流调整:果冻多就调低,动作卡就调高;
  • 开启转场识别,镜头切换处不插帧,避免鬼影;
  • 动漫片源建议先开去除重复帧再补帧,倍率先降到 2x~4x 试。
输出的视频没有声音?

最常见的原因是勾了静音 —— 这个选项是给“只要画面”的场景用的,取消勾选重新处理即可。 另外,源视频本身没声音,输出自然也没声音。

音频“升采样率”好像没效果?

这个功能只对低采样率源(8k / 16k / 22k / 32k,如电话录音、老磁带)真的有用,AI 会补出缺失的高频。 44.1 kHz 及以上的音乐本身已是全频带,软件会自动跳过,不报错也没变化 —— 这种情况改用「增强」。

状态栏显示“引擎缺失”或处理直接报错?
  1. 看软件目录下的 engines 文件夹是否完整(常见于安装包解压不完整,或被安全软件删了文件);
  2. 重新运行安装包覆盖安装一次,一般就能修好(设置与模型不会丢);
  3. 仍报错:打开「设置 → 诊断日志」看具体错误,或导出诊断包反馈给我们。
提示磁盘空间不足 / 临时文件占用很大?

视频处理要在临时目录保存大量中间帧,长视频可能占用几十 GB 甚至更多。软件会:

  • 处理前预估所需空间,不够就提前中止并提示;
  • 用完即删中间文件,并在启动时清理历史残留;
  • 允许在「设置」里指定临时文件位置 —— 空间紧张时指向空闲最大的盘。

另外建议把输出目录也放在剩余空间充足的分区,避免最后一步才失败。

收费与授权

软件收费吗?要注册账号吗?

个人 / 非商用使用免费,不用注册、不用登录,没有会员与内购,也没有功能锁在付费墙后。 软件内有合作方广告位以维持成本,不做个性化推荐,可以关闭(见下一条)。

广告能关掉吗?广告会读取我的信息吗?

可以。广告卡右上角「✕」能隐藏这一条;「设置 → 本次运行不显示广告」勾上后本次运行不再显示(重启会恢复,目前没有永久关闭开关)。 关掉广告不影响任何功能。

广告素材(文案与图片)从公开仓库拉取,这个过程不传输你的任何信息,不读取设备标识或使用记录。详见 隐私说明。

能商用吗?可以打包发给别人 / 上传到别的平台吗?

不可以。未经作者书面许可,禁止商用、售卖、出租、捆绑销售、以获利为目的的再分发,也禁止重新打包、改名后发布到其它渠道, 以及去除或篡改署名与版权声明。个人学习、研究与日常处理素材没问题。

软件本体是作者自创的专有许可(源码可见,但不是 MIT / Apache / GPL 这类标准开源许可); 集成的第三方组件(waifu2x、Real-ESRGAN、RIFE、FFmpeg 等)遵循各自许可,详见 开源许可与致谢。

打赏有什么用?不打赏会少功能吗?

打赏完全自愿,不影响任何功能,不构成购买,也没有额外特权或优先支持,不支持退还。 它只用于支持作者继续更新与维护。请理性打赏、量力而行。

隐私与联网

软件会把我的文件传到服务器吗?

不会。图片、视频、音频全部在你的电脑上处理,不上传文件内容,也不传文件名、路径、画面 / 音频或显卡机型等设备信息。 软件没有账号体系,不收集个人信息,也不做使用统计。

完整说明(哪三处会联网、每次做什么)见 隐私说明。

那软件为什么还要联网?都请求了什么?

只有三件事,都不涉及你的文件与设备信息:

  1. 检查更新:启动时查最新版本号,有新版本会提示(不自动下载、不自动安装);
  2. 拉取广告素材:取回界面广告位的文案与图片;
  3. 拉取界面提示文案:取回底部状态栏的提示条内容。

另外,点“问卷 / 更新下载”这类链接是你主动打开外部网页。以上请求失败都会被静默忽略,全都有内置兜底,不影响处理功能。

断网 / 内网环境能用吗?

能用。所有处理都是本机计算,不需要联网。那三件事(更新检查、广告素材、提示文案)失败时会被静默跳过: 提示条用内置文案、广告区隐藏、更新检查不提示,功能与画质不受影响。

只有下载安装包、下载模型包需要联网。

反馈问题时让我导出的“诊断包”里有什么?会不会被自动上传?

诊断包里是本机日志、设备信息与设置(用来定位问题),它只保存在你的电脑上,软件不会自动发送给任何人。 发不发、发给谁由你决定;不想发也可以只截取日志里的报错行。

其它

遇到问题想反馈,怎样最快解决?

带上这些信息,基本一轮就能定位:

  1. 软件版本号(「关于」页可看)与你的 Windows 版本;
  2. 显卡型号 + 驱动版本;
  3. 你做了什么、期望结果与实际结果;
  4. 「设置 → 诊断日志」里的相关日志,或用「导出诊断包」生成 zip。

建议优先去软件左下角的「ALH Pro 社区」反馈:软件里自带的入口,不用注册、也不用去 GitHub;使用问题、功能建议、处理效果都能在那儿聊。

教程描述和我在软件里看到的不一样?

软件更新较快,个别页面文字与教程正文可能有先后差异。更新日志 里记了每个版本的界面与默认值调整。 发现明显的说明错误,欢迎到「ALH Pro 社区」反馈。
