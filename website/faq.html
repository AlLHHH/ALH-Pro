下载与安装

下载很慢、或者中途断了怎么办?

按下面顺序试,一般三步之内就能解决:

  1. 使用百度网盘。完整版(约 2.4 GB,含全部模型)在 网盘 上,国内通常最快,提取码 yxfd。
  2. 给 GitHub 链接加加速前缀。在下载链接前拼一个公开镜像前缀,例如 https://gh-proxy.com/ + 原始下载链接,整条变成 https://gh-proxy.com/https://github.com/AlLHHH/ALH-Pro/releases/download/...。 免费、不用注册;镜像的可用性会变化,可以再换 ghproxy.net、ghproxy.com 等前缀。
  3. 错峰下载。清早或深夜通常比晚高峰稳,大文件支持断点续传,断了可以接着下。

镜像站是第三方公共服务,本项目无法保证其长期可用,也不对其内容负责。下载完成后请核对文件名、大小与 SHA256。

双击安装包后没反应,是卡死了吗?

多半不是。安装包体积较大,完整版约 2.4 GB,Windows 安全软件首次运行时会完整扫描,这段时间界面可能迟迟不出现, 等 1~2 分钟属正常;第一次扫描完成后,以后打开就快了。

如果等了几分钟仍然没有任何窗口,可以:①在任务管理器里看有没有安装程序进程在占 CPU / 磁盘;②把安装包复制到本地非系统盘再试; ③先按 SHA256 确认安装包完整(下载损坏也会导致双击无反应)。

杀毒软件报毒 / 提示“未知发布者”,怎么办?

先说明事实:安装包没有购买商业代码签名证书,所以 Windows 与部分安全软件会提示“未知发布者”, 或对“大体积未签名安装包 + 解压大量文件”这种典型行为给出拦截 / 误报提示。这是未签名软件很常见的现象。

建议顺序:

  1. 先核对 SHA256,确认文件与官方发布的一致;
  2. 一致的话,在安全软件里选择“允许 / 信任 / 加入白名单”,或把程序目录加入排除项;
  3. 如果文件被直接删除或隔离,请恢复并信任后重试;若反复被删,请把报毒名称与截图反馈给我们,便于进一步排查。

请只从官方渠道下载,即本页顶部的 GitHub Releases 与作者百度网盘。 第三方下载站、网盘转发、“绿色版”等来源的安装包可能被重新打包,那种情况下的报毒就真的不能信任了。

需要先装 .NET 吗?提示缺少运行库怎么办?

正常不需要。ALH Pro 的安装包是自包含的(self-contained .NET 8),运行库已经打在包里, 不需要你另外安装 .NET,也不需要 Visual C++ 运行库。

如果仍然遇到与运行库相关的提示,按这个顺序排查:

  1. 确认系统是 64 位 Windows 10(1809 / 内部版本 17763 及以上)或 Windows 11。比这更旧的系统, 安装程序会直接拦下(装上也运行不了)。
  2. 确认下载的安装包完整(体积对得上、SHA256 对得上),损坏的安装包会出现解压 / 加载失败。
  3. 个别系统组件缺失时,可以到微软官网自行安装 .NET 8 Desktop Runtime(x64) 后再启动软件。
  4. 仍然不行:在「设置 → 诊断日志」导出日志包反馈给我们,日志里通常能直接看出原因。
能装到别的盘吗?需要管理员权限吗?

默认装到当前用户目录 C:\Users\你的用户名\AppData\Local\Programs\ALH Pro,不需要管理员权限 (这也是默认位置的用意:避免写不进 Program Files 导致模型装不上)。

安装向导里可以改成其它目录;如果选 Program Files,安装程序会请求管理员权限。装在系统盘之外也可以,不影响功能。 处理视频时会在临时目录产生中间帧,临时文件位置可以在「设置」里指定,建议指向空闲空间最大的盘。

支持 32 位系统、Windows 7、Mac 或手机吗?

都不支持。ALH Pro 是 Windows 10 / 11 的 64 位(x64)桌面程序: 32 位 Windows、Windows 7 及更早系统、macOS、Linux、iOS / Android 均无法运行,也没有对应的版本计划。

怎么升级?需要先卸载旧版、重新下模型吗?

不需要卸载,也不需要重新装模型。直接下载新安装包覆盖安装即可:程序会被新版覆盖,引擎、模型与设置原样保留。 设置、预设、处理记录保存在 %LOCALAPPDATA%,覆盖安装不会动到它们。

有个例外请留意:如果某个版本调整了后处理参数的“机理”,旧预设里的数值含义可能变过, 该版本的更新说明里会专门提醒(更新日志 会写清楚)。

启动时软件会自动检测 GPU:有独立显卡且引擎兼容就自动启用;不兼容时自动改走稳定的兼容路线, 输出结果不受影响,只是速度有差别。想确认自己走的是哪条路,看页面上方的设备提示(例如“自动使用兼容加速(DirectML)”)。

RTX 50 系为什么会被提示走了“兼容路线”?

50 系是较新的架构,部分内置引擎(基于 ncnn-Vulkan)在早期驱动上与它不完全兼容。软件已经自动适配: 检测到 50 系时会自动选择稳定的引擎路线(ONNX / DirectML),显卡仍然参与加速(不是退回纯 CPU),输出结果不受影响, 页面上会有明确提示(例如“已按此显卡自动选用稳定引擎处理”)。你不需要手动设置。

从 v1.3.5 起,补帧引擎已用新版 ncnn 源码重编,50 系不再只能等驱动修复。

提示“驱动偏旧 / 改走兼容路线”,一定要更新驱动吗?

不是必须,但更新显卡驱动后重启软件,通常能恢复完整的 GPU 加速。老驱动(2021 年以前)的 30 / 20 / 16 系与部分 AMD 显卡上, 引擎可能起不来,软件会自动降级(慢但稳)。

另外内置的视频编码器(NVENC)需要较新的 NVIDIA 驱动,驱动过旧时软件会改用 CPU 软编码并提示你 —— 不更新也能跑,只是慢。

处理很慢,正常吗?

先看下面几条最常见的“慢”的原因:

  • 是不是在用 CPU?CPU 模式比 GPU 慢几倍到十几倍。看页面上方的设备提示,以及状态栏 / 日志里写的实际计算设备。
  • 倍率是不是太高?4x 超分 / 8x 以上补帧的耗时和磁盘占用会成倍上升。老电脑建议先试 1x 超分、2x 补帧。
  • 模型是不是“质量优先”那类?同样 1080p 超分,动漫视频常用的轻量模型每帧约 0.25 秒,而 x4plus 这类质量模型约 15 秒/帧, 差距非常大。先用轻量模型试效果。
  • 素材是不是 4K / 高帧率?4K 补帧单输出帧大约是 1080p 的 3 倍多耗时。
  • 音频分离本身慢。优先用显卡(DirectML)加速;没有可用显卡时用 CPU,一首歌几到十几分钟。

状态栏会显示进度与已用时间;v1.3.3 起四个阶段都有各自的剩余时间估计。建议先用一小段样片试跑,确认参数和耗时再整段处理。

大概多久能跑完一段视频?有参考数据吗?

以下为本机实测的量级,测试机为 RTX 4060 Laptop:

  • 1080p 超分:动漫视频常用模型约 0.25 秒/帧(4x 约 0.30 秒/帧),轻量通用模型 4x 约 0.46 秒/帧,质量优先的 x4plus 约 15 秒/帧;
  • 1080p 补帧:约 0.08 秒/输出帧;2160p(4K)约 0.28 秒/输出帧;
  • 一个真实作业:1080p、72 帧素材(约 2.4 秒),做 4 倍补帧 + 2 倍超分,全程约 53.7 秒。

以上为本机实测数字,并非承诺。更换显卡、模型或素材后差别可能较大,请以软件内显示的预计剩余时间为准,并先用样片试跑。

功能与效果

AI 抠图提示“模型未安装”,怎么装?

安装包不含抠图模型(约 1.4 GB),需要单独补。两种办法:

  1. 重新运行安装包,在「选择附加任务」页勾选「下载并安装模型包」;
  2. 或手动下载 models_v1.0.zip,把里面的 6 个 .onnx 文件直接解压到 程序目录\engines\rembg\(不要再套一层文件夹)。

装好的标志:AI 抠图页左上角的黄色提示消失。完整步骤见 使用教程 · 抠图模型怎么装。实在嫌麻烦就用完整版安装包(含全部模型)。

放大后图发糊 / 变得像画出来的,是哪里设错了?
  • 动漫图发糊 → 检查算法是不是选成了 Real-ESRGAN;动漫 / 插画应该用 waifu2x。
  • 照片显得很“画” → 检查是不是用了 waifu2x;照片 / 实拍应该用 Real-ESRGAN。
  • 图发虚、有马赛克 → 倍率可能偏高,或超分引擎选错;先试 1x 超分(只变清晰不放大)。
  • 细节被磨掉了 → 降噪档位太强。干净素材请用“不降噪 / 弱”,强档只适合压缩噪点明显的素材。
抠图边缘粗糙 / 缺了一块,怎么调?
  • 提高「边缘增强」,或换成 ISNet 精细边缘(人像 / 产品)、ISNet 动漫(动漫插画);
  • 背景与主体颜色接近时,适当降低前景阈值、提高背景阈值,或勾「自适应阈值」;
  • 抠毛发、半透明边缘时调高「边缘羽化」;
  • 边缘有碎点杂色时开启「边缘清理」。

小提示:先用一张图把参数调好,再点批量,避免整批返工。

补帧之后画面有“果冻”扭曲 / 动作反而怪?
  • 勾上「果冻修复」,给快速运动处盖一层真实运动模糊,观感更自然;
  • 调「光流调整」:果冻多就调低,动作卡就调高;
  • 开启「转场识别」,镜头切换处不插帧,避免鬼影;
  • 动漫片源建议先开「去除重复帧」再补帧,并把倍率降到 2x~4x 试效果。
输出的视频没有声音?

最常见的原因是勾了「静音」——这个选项是为“只要画面”的场景准备的。取消勾选后重新处理即可。 另外注意:如果源视频本身就是无声的(例如某些无声素材),输出自然也没有声音。

音频“升采样率”好像没效果?

这个功能只对低采样率源(8k / 16k / 22k / 32k,例如电话录音、老磁带)真的有作用,AI 会补出缺失的高频。 44.1 kHz 及以上的音乐本身已是全频带,软件会自动跳过,不会报错,也不会有变化 —— 这种情况请改用「增强」。

状态栏显示“引擎缺失”或处理直接报错?
  1. 检查软件目录下的 engines 文件夹是否完整(通常是安装包解压不完整或被安全软件删了文件);
  2. 重新运行安装包覆盖安装一次,一般即可修复(设置与模型不会丢);
  3. 仍然报错:打开「设置 → 诊断日志」看具体错误,或导出诊断包反馈给我们。
提示磁盘空间不足 / 临时文件占用很大?

视频处理需要在临时目录保存大量中间帧,长视频可能占用几十 GB 甚至更多。软件会:

  • 处理前预估所需空间,不足时提前中止并提示(不会偷偷写满磁盘);
  • 用完即删中间文件,并在启动时清理历史残留;
  • 允许在「设置」里指定临时文件位置 —— 空间紧张时请指向空闲最大的盘。

另外建议把输出目录也放在剩余空间充足的分区,避免处理到最后一步才失败。

收费与授权

软件收费吗?要注册账号吗?

个人 / 非商用使用免费,不需要注册、不需要登录、没有会员与内购,也没有功能被锁在付费墙后。 软件内有合作方广告位以维持开发与维护成本,广告不做个性化推荐,可以在设置里关闭(见下一条)。

广告能关掉吗?广告会读取我的信息吗?

可以。广告卡右上角「✕」可隐藏当前这一条;「设置 → 本次运行不显示广告」勾上后,本次运行不再显示(重启软件会自动恢复显示; 目前没有“永久关闭广告”的开关)。关闭广告不影响软件的任何功能。

广告素材(文案与图片)从公开仓库拉取用于界面展示,这个过程不传输你的任何信息,也不读取设备标识或使用记录, 不做个性化推荐。详见 隐私说明。

能商用吗?可以打包发给别人 / 上传到别的平台吗?

不可以。未经作者书面许可,禁止商用、售卖、出租、捆绑销售、以获利为目的的再分发,也禁止重新打包、改名后发布到其它渠道, 以及去除或篡改软件内的署名与版权声明。个人学习、研究、日常处理素材完全没问题。

软件本体采用作者自创的专有许可(源码可见,但不是 MIT / Apache / GPL 这类标准开源许可); 随软件集成的第三方开源组件(waifu2x、Real-ESRGAN、RIFE、FFmpeg 等)仍遵循各自的许可,详见 开源许可与致谢。

打赏有什么用?不打赏会少功能吗?

打赏完全自愿,不影响任何功能,不构成购买,也不提供额外特权或优先支持,且不支持退还。 打赏只用于支持作者继续更新、修复与维护本项目。请理性打赏、量力而行;未成年人请在监护人知情同意下操作。

隐私与联网

软件会把我的文件传到服务器吗?

不会。图片、视频、音频的处理全部在你的电脑上完成,不上传文件内容、不传文件名、不传文件路径、不传画面/音频, 也不传显卡机型等设备信息。软件没有账号体系,不收集个人信息,也不做使用行为统计。

完整说明(包括软件里哪三处会联网、每次联网做什么)见 隐私说明。

那软件为什么还要联网?都请求了什么?

只有三件事,而且都不涉及你的文件与设备信息:

  1. 检查更新:启动时查询最新版本号,有新版本会提示你(不自动下载、不自动安装);
  2. 拉取广告素材:获取界面广告位的文案与图片;
  3. 拉取界面提示文案:获取底部状态栏的提示条内容。

另外,点“问卷 / 更新下载”这类链接时是你自己主动打开外部网页。以上所有请求失败都会被静默忽略, 全部有内置兜底(提示有内置文案、广告区直接隐藏),不影响任何处理功能。

断网 / 内网环境能用吗?

能用。所有处理都是本机计算,不需要联网。联网的三件事(更新检查、广告素材、提示文案)失败时会被静默跳过: 提示条会显示内置的默认文案,广告区隐藏,更新检查不做提示。功能与画质不受任何影响。

只有下载安装包、下载模型包需要联网。

反馈问题时让我导出的“诊断包”里有什么?会不会被自动上传?

诊断包里是本机日志、设备信息与设置(用于定位问题),它只保存在你的电脑上, 软件不会自动发送给任何人。是否发给我们、发给谁,完全由你决定;不想发也可以只截取日志里的报错行。

其它

遇到问题想反馈,怎样最快解决?

带上这些信息,基本一轮就能定位:

  1. 软件版本号(「关于」页可看)与你的 Windows 版本;
  2. 显卡型号 + 驱动版本;

反馈渠道:软件内「关于 → 联系方式」或社区(见软件内说明)。

软件更新较快,个别页面文字与教程正文可能有先后差异。更新日志 里记录了每个版本的界面与默认值调整 (例如去重的默认档位、广告开关的行为、图片后处理参数的机理变化等)。如果发现明显的说明错误,欢迎反馈,我们会尽快更正。
