校验方法

下载完成后,在文件所在的文件夹中打开 PowerShell:在文件夹空白处按住 Shift 点击右键,选择“在此处打开 PowerShell 窗口”或“在终端中打开”,然后执行:

Get-FileHash .\ALHPro_v1.3.6_Setup.exe -Algorithm SHA256

把命令里的文件名换成你实际下载的文件名(例如完整版或 models_v1.0.zip)。

习惯用 CMD(命令提示符)的话,等价命令是:

certutil -hashfile ALHPro_v1.3.6_Setup.exe SHA256

命令行会输出一串 64 位的十六进制字符,把它和本页表格里的值逐字符对照:

  • 完全一致 → 文件完整、与官方发布的一致,可以放心安装。
  • 不一致 → 文件可能下载损坏或被篡改。请不要安装,删除后重新下载;仍然不一致就别运行它。

对照时注意:大小写不影响结果(有的工具输出大写),空格和换行不影响。

安装步骤

  1. 下载安装包(标准版或完整版),并核对 SHA256。
  2. 双击运行。默认安装位置是当前用户目录 C:\Users\你的用户名\AppData\Local\Programs\ALH Pro,不需要管理员权限;想装到别处可以自己改,选 Program Files 时会要求管理员权限。
  3. 一路“下一步”。在「选择附加任务」页会出现一个可选项「下载并安装模型包(约 1.4 GB,来自 GitHub)」—— 需要 AI 抠图就勾上(勾上后安装程序会自己去下载并解压);不勾也没关系,以后随时单独装。
  4. 如果没勾模型包、之后要用 AI 抠图:下载 models_v1.0.zip,把里面的 6 个 .onnx 文件 直接解压到 程序目录\engines\rembg\(不要再套一层文件夹)。模型装好的标志:AI 抠图页左上角的黄色提示消失。 详细图文见 使用教程。
  5. 首次启动需等待 1~2 分钟。Windows 的安全软件会完整扫描程序和安装包,这段时间双击后可能“没反应”,并非卡死; 等第一次扫描完成后,以后启动就快了。
  6. 开始使用:左侧选功能(图片放大 / AI 抠图 / 视频处理 / 音频处理)→ 添加素材 → 调整参数 → 点「开始处理」。

从旧版本升级

  • 直接下载新安装包覆盖安装即可:引擎、模型与设置都会保留,不需要先卸载,也不需要重新下载模型。
  • 设置、预设、处理记录保存在 %LOCALAPPDATA%,覆盖安装不会动它们。
  • 软件内「设置」可以勾选「不再提示更新」;默认情况下启动时会检查一次是否有新版本(见 隐私说明 · 联网行为)。

安全软件拦截与“未知发布者”提示

安装包没有购买商业代码签名证书,所以 Windows 与部分安全软件可能提示“未知发布者”,或对安装包、解压行为做出拦截提示。 这是未签名软件的常见现象,不代表文件含恶意代码。建议按以下顺序处理:

  1. 先按上文核对 SHA256,确认文件就是官方发布的那一个;
  2. 确认无误后,在安全软件里选择“允许 / 信任”,或把安装包与程序目录加入白名单;
  3. 若杀软仍直接删除文件,请把具体报毒名反馈给我们。 更多问答见 常见问题 · 杀毒软件报毒 / 拦截。
