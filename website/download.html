系统要求

项目要求
操作系统Windows 10 1809 及以上 / Windows 11,仅 64 位(x64)。32 位系统与 Windows 7 不支持
.NET 运行库已内置,不用单独装 .NET;安装包里已带 Windows App SDK。若提示缺少运行库,见 常见问题
处理器任意 x64 处理器。没有独显也能跑,只是自动改用 CPU,慢数倍到十几倍
内存建议 8 GB 及以上。低于 8 GB 会按「弱设备」处理,并提示可开「兼容模式」
显卡建议 NVIDIA RTX 30 / 40 系(最稳)。RTX 50 系自动走 ONNX / DirectML 稳定路线,速度略降但结果不变;AMD、Intel Arc、核显可用但可能降级。对照表见 常见问题 · 显卡能不能用
显存建议 6 GB 及以上。不够时自动降低分块,变慢但不报错
磁盘空间安装占约 0.9 GB(完整版约 2.6 GB)。处理视频会在临时目录产生中间帧,长视频建议预留与素材同量级的空闲空间
权限默认装到当前用户目录,不需要管理员权限;装到 Program Files 才会请求
网络只在下载时需要。软件运行期间只有三处联网(检查更新、广告素材、界面提示文案),失败不影响使用,见 隐私说明

安装步骤

  1. 下载安装包(标准版或完整版),认准文件名与大小。
  2. 双击运行。默认装到 C:\Users\你的用户名\AppData\Local\Programs\ALH Pro,不需要管理员权限;想换目录可以自己改。
  3. 一路「下一步」。「选择附加任务」页会有一个可选项「下载并安装模型包(约 1.4 GB)」,要用 AI 抠图就勾上;不勾也行,以后随时单独装。
  4. 没勾模型包、之后要用 AI 抠图:下载 models_v1.0.zip,把里面 6 个 .onnx 文件 直接解压到 程序目录\engines\rembg\(不要再套一层文件夹)。装好的标志:AI 抠图页左上角的黄色提示消失。
  5. 首次启动可能要等 1~2 分钟。安全软件会完整扫描一次,双击后「没反应」是正常的,扫过之后启动就快了。
  6. 开始使用:左侧选功能 → 添加素材 → 调参数 → 点「开始处理」。

从旧版本升级

  • 直接下新安装包覆盖安装:引擎、模型与设置都保留,不用先卸载,也不用重新下模型。
  • 设置、预设、处理记录保存在 %LOCALAPPDATA%,覆盖安装不会动它们。
  • 启动时会检查一次新版本,可在「设置」里勾「不再提示更新」(见 隐私说明 · 联网行为)。

下载速度慢或中断

情况可以试的办法
GitHub 打得开,但下载慢或经常断 给下载链接加一个公开镜像前缀,例如 https://gh-proxy.com/https://github.com/AlLHHH/ALH-Pro/releases/download/...。 免费、不用注册。
镜像也慢、或者一直失败 换别的镜像前缀(如 ghproxy.net、ghproxy.com),或者错峰下载。
不想折腾,只想快点跑起来 直接用 百度网盘完整版(约 2.0 GB,含全部模型,提取码 6eym)。

镜像站是第三方服务,不保证长期可用。它只是代理访问,不是第三条官方渠道。

安全软件拦截与“未知发布者”提示

安装包没有购买商业代码签名证书,所以 Windows 与部分安全软件可能提示“未知发布者”或拦截。这是未签名软件的常见现象。

  1. 先确认文件名与大小对得上(官方渠道的文件);
  2. 确认无误后,在安全软件里选“允许 / 信任”,或加入白名单;
  3. 仍被直接删除,就带报毒名到「ALH Pro 社区」反馈,更多问答见 常见问题 · 杀毒软件报毒 / 拦截。
