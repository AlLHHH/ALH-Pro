在你自己的电脑上, 做 AI 视频 / 图片处理

ALH Pro 是一款 Windows 桌面软件:把模糊的老番、老照片变清晰(超分),把卡顿的视频变流畅(补帧), 一键去掉图片背景(抠图),还能把电话录音、老磁带里的声音变清楚(音频增强),顺带处理动漫片源里的重复帧。 全部处理都在您的电脑上完成:不注册账号、不上传文件。

这是给谁用的

想让老番、老片变清晰的动漫爱好者

动漫 / 插画走 waifu2x 路线,线条和色块更干净;配合“去重复帧”,补帧结果更准、文件更小。

要放大照片、修图的人

照片 / 实拍走 Real-ESRGAN 路线,1x 超分(只变清晰不放大)到 4x 放大都支持,可批量处理。

要批量去背景做素材的人

6 款抠图模型,人像、产品、动漫各有合适的一支;支持批量、边缘羽化与边缘增强,输出透明 PNG。

不放心把素材传到云端的人

素材处理全程在本机完成,不需要登录,不经过任何服务器。处理重要素材前请自行备份原文件。

能做什么

图片 / 视频超分

  • 动漫插画:waifu2x(cunet / upconv_7_anime)
  • 真实照片:Real-ESRGAN
  • 1x 超分(只变清晰不放大)到 4x 放大
  • 降噪(弱 / 中 / 强)、去雾、锐化、去模糊、边缘抗锯齿等后处理
  • 批量处理,输出 JPG / PNG

视频补帧(变流畅)

  • RIFE 引擎,默认 v4.13,可选多支模型
  • 输出帧率 = 原帧率 × 倍率(2x / 3x / 4x / 8x / 12x / 16x)
  • 可变帧率(VFR)录屏、手机、监控素材自动按原节奏处理
  • 果冻修复、光流调整、转场识别,减少鬼影与扭曲

去除重复帧(动漫必备)

  • 智能检测(自动估节奏)、动漫模式(去一拍二 / 三 / 四)、手动模式
  • 支持相位自动对齐,避免抽到中间帧
  • 去重 + 补帧:时长保持与源一致(尾帧保留),帧率 = 内容帧率 × 倍率

AI 抠图

  • U²-Net(通用 / 轻量)、ISNet(精细边缘 / 动漫)、BiRefNet(高精度 / 完整版)共 6 款模型
  • 前景 / 背景阈值、边缘羽化、边缘增强、边缘清理
  • 彩色预览(原图 × 蒙版,棋盘格 = 透明区域)

音频处理

  • AI 升采样率:8k / 16k / 22k / 32k 低采样率源 → 48 kHz
  • 增强:人声 / 伴奏分别优化后重混
  • AI 分离(Demucs):提取人声、去人声(卡拉OK)、分离或自定义多轨输出
  • 降噪、响度归一、低切、清晰增强,输出 WAV / FLAC / MP3

长视频也敢跑

  • 显存 / 内存 / CPU 占用按本机配置自动调节
  • 处理时降低进程优先级、支持设备降温休息
  • 临时文件自动清理,处理前预估磁盘占用,不足会提前提示
  • 批量队列:拖拽排序、完成置灰、只处理选中项

三步开始

  1. 下载安装。标准版安装包约 827 MB;要用「AI 抠图」再装模型包(约 1.4 GB),或直接下载完整版(约 2.4 GB,装完所有功能可用)。安装不需要管理员权限,一路“下一步”即可。 详见 下载页。
  2. 添加素材、选算法。左侧选功能(图片放大 / AI 抠图 / 视频处理 / 音频处理) → 添加文件 → 选算法与倍率。 动漫插画选 waifu2x、照片选 Real-ESRGAN,选错效果会明显变差,对照表见 使用教程。
  3. 点“开始处理”。输出默认与源文件同目录,多文件会自动建子文件夹。处理过程有进度与预计剩余时间,可随时停止。

您的文件不会离开这台电脑

  • 不上传:图片、视频、音频的内容与中间文件全部在本机处理,不上传到任何服务器。
  • 不传文件名 / 路径 / 画面 / 机型:软件不会把您的文件名、文件路径、画面内容或显卡机型等信息发出去。
  • 不需要账号:没有注册、没有登录、没有云端记录。
  • 三处联网行为如实列出:①启动时检查新版本;②拉取界面广告素材;③拉取界面提示文案。 三者都只请求公开的文本 / 图片,并且失败时全部有内置兜底,不影响任何处理功能。
  • 诊断包是您主动生成的:“导出诊断包”会打包本机日志与设备信息,只保存在本机,发不发、发给谁由您决定。
