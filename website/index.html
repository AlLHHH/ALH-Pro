在你自己的电脑上, 做 AI 视频 / 图片处理

ALH Pro 是一款 Windows 桌面软件:超分让模糊的老番、老照片变清晰,补帧让卡顿的视频变流畅, 抠图一键去掉图片背景,音频增强让电话录音与老磁带的声音变清楚,并可处理动漫片源中的重复帧。 全部处理均在本机完成,不需要注册账号,也不上传文件。

  • 全程本地运行
  • 不上传任何文件
  • 个人 / 非商用免费
  • Windows 10 / 11 x64
  • 当前版本 v1.3.6
下载最新版 v1.3.6 看使用教程

标准版安装包约 827 MB,完整版约 2.4 GB 并含全部模型。首次安装需预留磁盘空间与几分钟时间。

适用人群

想让老番、老片变清晰的动漫爱好者

动漫 / 插画走 waifu2x 路线,线条和色块更干净;配合“去重复帧”,补帧结果更准、文件更小。

要放大照片、修图的人

照片 / 实拍走 Real-ESRGAN 路线,支持 1x 超分至 4x 放大。1x 只提升清晰度,不改变尺寸。

要批量去背景做素材的人

6 款抠图模型,人像、产品、动漫各有合适的一支;支持批量、边缘羽化与边缘增强,输出透明 PNG。

不放心把素材传到云端的人

素材处理全程在本机完成,不需要登录,不经过任何服务器。处理重要素材前请自行备份原文件。

图片 / 视频超分

超分:把原片里被压掉、被糊掉的细节重新算回来。动画左边是原片放大后的样子 —— 只剩大色块;右边是 4x 超分后的同一个画面,尺寸变 4 倍、线条顺滑、细节回得来。1x 只提升清晰度,不放大尺寸。

  • 动漫插画:waifu2x(cunet / upconv_7_anime)
  • 真实照片:Real-ESRGAN
  • 1x 超分至 4x 放大,1x 只提升清晰度、不改变尺寸
  • 降噪(弱 / 中 / 强)、去雾、锐化、去模糊、边缘抗锯齿等后处理
  • 批量处理,输出 JPG / PNG
原片 24fps
补帧后 60fps

视频补帧

补帧:在相邻两帧之间算出中间帧,把动作接起来。动画里是同一个球在走:上面那行按原片 24fps 走,一跳一跳;下面那行补到 60fps 之后连续顺滑,多出来的刻度就是新生成的中间帧。倍率可选 2x / 3x / 4x / 8x / 12x / 16x。

  • RIFE 引擎,默认 v4.13,可选多支模型
  • 输出帧率 = 原帧率 × 倍率(2x / 3x / 4x / 8x / 12x / 16x)
  • 可变帧率(VFR)录屏、手机、监控素材自动按原节奏处理
  • 果冻修复、光流调整、转场识别,减少鬼影与扭曲
原片:6 帧(一拍二) 去重后:3 帧 · 时长不变

去除重复帧

去重:删掉画面完全相同的重复帧。动画里 6 帧中有一半跟前一帧一模一样 —— 这就是动漫常见的「一拍二」;去除后只剩 3 帧:帧数少一半,时长和节奏不变,再拿去补帧也不会把同一张画面重复补一遍。

  • 智能检测(自动估节奏)、动漫模式(去一拍二 / 三 / 四)、手动模式
  • 支持相位自动对齐,避免抽到中间帧
  • 去重 + 补帧:时长与源一致,尾帧保留;帧率 = 内容帧率 × 倍率
原图(有背景) 背景已抠掉 · 棋盘格=透明

AI 抠图

抠图:把主体留下、背景变透明。动画里实色背景被擦掉,露出棋盘格(它就是"透明"的画法),虚线框是软件识别出的主体边缘 —— 抠完可以直接叠到别的画面上。人像、产品、动漫各有合适的模型。

  • U²-Net(通用 / 轻量)、ISNet(精细边缘 / 动漫)、BiRefNet(高精度 / 完整版)共 6 款模型
  • 前景 / 背景阈值、边缘羽化、边缘增强、边缘清理
  • 彩色预览(原图 × 蒙版,棋盘格 = 透明区域)

增强后

音频处理

音频增强:把底噪压下去、人声提上来。动画上面那行是处理前的波形 —— 毛刺多、抖得乱;下面那行是增强后的:同一个周期里起伏干净、人声轮廓清楚。另有升采样率(8k~32k → 48kHz)与 AI 分轨。

  • AI 升采样率:8k / 16k / 22k / 32k 低采样率源 → 48 kHz
  • 增强:人声 / 伴奏分别优化后重混
  • AI 分离(Demucs):提取人声、去人声(卡拉OK)、分离或自定义多轨输出
  • 降噪、响度归一、低切、清晰增强,输出 WAV / FLAC / MP3
一格 = 一批 · 每批做完即清临时文件

长视频处理

长视频:按本机显存与内存自动分批,一批做完再起下一批。动画里进度条前进、每一小格代表一批 —— 处理前会预估磁盘占用,不够就提前提示;临时文件用完即清,处理时还会自动降低进程优先级,支持设备降温休息。

  • 显存 / 内存 / CPU 占用按本机配置自动调节
  • 处理时降低进程优先级、支持设备降温休息
  • 临时文件自动清理,处理前预估磁盘占用,不足会提前提示
  • 批量队列:拖拽排序、完成置灰、只处理选中项

三步开始

  1. 下载安装。标准版安装包约 827 MB;需要「AI 抠图」时再安装模型包约 1.4 GB,或直接下载完整版约 2.4 GB,安装后所有功能可用。安装不需要管理员权限,按向导完成即可。 详见 下载页。
  2. 添加素材、选算法。左侧选功能(图片放大 / AI 抠图 / 视频处理 / 音频处理) → 添加文件 → 选算法与倍率。 动漫插画选 waifu2x、照片选 Real-ESRGAN,选错效果会明显变差,对照表见 使用教程。
  3. 点“开始处理”。输出默认与源文件同目录,多文件会自动建立子文件夹。处理过程显示进度与预计剩余时间,可随时停止。

您的文件不会离开这台电脑

  • 不上传:图片、视频、音频的内容与中间文件全部在本机处理,不上传到任何服务器。
  • 不传文件名 / 路径 / 画面 / 机型:软件不会把您的文件名、文件路径、画面内容或显卡机型等信息发出去。
  • 不需要账号:没有注册、没有登录、没有云端记录。
  • 三处联网行为如实列出:①启动时检查新版本;②拉取界面广告素材;③拉取界面提示文案。 三者都只请求公开的文本 / 图片,并且失败时全部有内置兜底,不影响任何处理功能。
  • 诊断包是您主动生成的:“导出诊断包”会打包本机日志与设备信息,只保存在本机,发不发、发给谁由您决定。
