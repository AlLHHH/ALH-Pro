6 款抠图模型,人像、产品、动漫各有合适的一支。支持批量,输出透明 PNG。

不放心把素材传到云端的人

全程在本机处理,不用登录,不经过任何服务器。

视频补帧

补帧 = 在相邻两帧之间算出中间帧,把动作接起来。上面那行按原片 24fps 走,一跳一跳;下面补到 60fps 后就连续顺滑了。

  • RIFE 引擎,默认 v4.13,可选多支模型
  • 输出帧率 = 原帧率 × 倍率(2x / 3x / 4x / 8x / 12x / 16x)
  • 录屏、手机、监控这类帧率不均匀的素材,自动按原节奏处理
  • 果冻修复、光流调整、转场识别,减少鬼影与扭曲
原片:6 帧(一拍二) 去重后:3 帧 · 时长不变

去除重复帧

去重 = 删掉画面完全相同的重复帧。上面 6 帧里有 3 帧跟前一帧一模一样(动漫常见的「一拍二」),去重后只剩 3 帧,时长和节奏不变。

  • 智能检测(自动估节奏)、动漫模式(去一拍二 / 三 / 四)、手动模式
  • 相位自动对齐,避免抽到中间帧
  • 去重 + 补帧:时长与源一致,帧率 = 内容帧率 × 倍率
原图(有背景) 背景已抠掉 · 棋盘格=透明

抠图 = 主体留下、背景变透明。棋盘格就是「透明」的画法,虚线框是软件识别出的主体边缘。

音频处理

音频增强 = 把底噪压下去、人声提上来。上面那行是处理前的波形,毛刺多;下面那行干净、人声轮廓清楚。

一格 = 一批 · 每批做完即清临时文件

长视频处理

长视频:按本机显存与内存自动分批,一批做完再起下一批。每一小格代表一批,处理前会预估磁盘占用,不够就提前提示。

  • 显存 / 内存 / CPU 占用按本机配置自动调节
  • 处理时降低进程优先级、支持设备降温休息
  • 临时文件自动清理,处理前预估磁盘占用,不足会提前提示
  • 批量队列:拖拽排序、完成置灰、只处理选中项

设备适配(电脑要求)

一句话:Windows 10 / 11 的 64 位电脑就能用。有独立显卡会快一些,其中 NVIDIA 优先优化; 没有独显、或用 AMD / Intel 显卡也能跑,只是自动走更稳的路线、慢一些。机器偏弱时软件会自动减小分块与每批帧数,变慢但把活干完。 逐项清单见 下载页的系统要求。

系统

Windows 10(1809 及以上)/ Windows 11,仅 64 位。32 位系统与 Windows 7 及更早版本装不上,不是慢的问题。

  • Windows 10 / 11支持(64 位)
  • Windows 7 及更早不支持
  • 32 位系统不支持
  • .NET 运行库已内置,不用单独装

显卡

NVIDIA 优先优化;AMD、Intel 可用,但没有做专门优化,可能自动走更稳的路线或改用 CPU。

  • NVIDIA RTX 30 / 40 系最稳,走 GPU 加速
  • NVIDIA RTX 50 系可用,自动改用更稳的引擎路线
  • NVIDIA 20 / 16 / 10 系可用;驱动偏旧时可能自动降级
  • AMD · Intel 独显可用,未做专门优化,可能降级
  • 核显 / 无独显能跑,但会慢很多(自动改用 CPU)

用哪块卡、走哪条路线由软件自动判断,不用你设置;逐显卡的完整对照表见 常见问题 · 显卡能不能用。

显存

显存越大,分块越大、越快;显存不够就自动降档重试 —— 不会失败,只是变慢。

  • 8 GB 档及以上分块 1024(实测最优档)
  • 5.5 ~ 7.5 GB分块 768
  • 3.5 ~ 5.5 GB分块 640
  • 不足 3.5 GB / 核显分块 512(最保守)
  • 显存不够用时自动降档重试:自动 → 512 → 256 → 128

分块越小越省显存,但更慢。视频逐帧超分另有一套档位(4 GB 以下 256,6 GB 档 512,8 GB 档 640,12 GB 档 768)。

内存

建议 8 GB 及以上。内存只影响快慢,不影响能不能跑。

  • 空闲内存 ≥ 8 GB每批最多 350 帧;片子长且实测够快可到 700 帧
  • 空闲内存 4 ~ 8 GB每批 300 帧
  • 空闲内存不足 4 GB每批 50 帧起(最低档,求稳)

内存与显存都按「留 25% 给系统」来算。内存不足 8 GB、显存不足 6 GB 或 CPU 核心 ≤ 4 时,软件会提示可开「兼容模式」。

磁盘与临时盘

处理前先预估临时空间并告诉你;不够会提前中止,不会跑到一半爆盘。

  • 处理前提示「本任务预计需要约 X GB」与临时目录位置
  • 空间不够明确提示并中止,建议清理磁盘 / 降低倍率 / 换盘
  • 空间偏紧自动降低每批帧数,压低同时占盘的临时帧
  • 临时目录默认自动选剩余空间最大的本地盘,也可自己指定

长视频 + 高倍率(8x 补帧再超分)的临时峰值可达数十 GB,建议把临时目录放在空闲最大的盘。 安装占用见 下载页系统要求。
