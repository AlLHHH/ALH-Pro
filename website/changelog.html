v1.4.0 2026-09-16 · 新增超分模型与两支测试模型 + 视频「边缘增强」+ 下拉重排 + 超分提速与黑帧降级修复

新增自研转换的超分模型、两支标着「测试」的自训 2x 模型、视频「边缘增强」后处理,超分模型下拉重排(老设置自动迁移);修复「指定帧率」下临时空间被算少一半的问题,并集中修掉一批"不报错、只是慢或悄悄做错"的问题 —— 8GB 显卡超分提速约 1.6 倍、超分遇到黑帧不再整批重跑几十分钟
  • 新增超分模型 realesr-general-wdn-x4v3(自研转换): 权重取自上游 Real-ESRGAN 官方 release v0.2.5.0(BSD 3-Clause),本项目自行转成 ncnn 与 ONNX 格式。 1080p 约 0.46 秒/帧,游戏、动漫素材上的细节优于原来的默认模型。
  • 新增两支自训 2x 模型「现实 · real2x / 游戏 · game2x」(下拉里带一个蓝色「测试」小标): 定位是先把颜色调准 —— 实测色偏(越小越准)三档都低于官方默认模型:游戏帧 0.18 / 0.34(官方 2.00)、动漫帧 0.04 / 0.18(官方 2.73)、实拍 2.53 / 1.48(官方 6.34); 代价是纹理量(detail)多数低于官方默认模型(游戏帧 2.36 / 3.20 对 2.91、动漫帧 1.55 / 1.83 对 2.06、实拍 59.97 / 59.13 对 73.66 —— 只有游戏帧上「现实 · real2x」的 3.20 略高于官方 2.91)。所以这两个位置只给实测数字,不写“更强 / 推荐”。
  • ⚠ 关于这两支的两条边界:
    • 通道验收已通过:引擎输出与源逐通道均值差 小于 0.4 级(判据 小于 5)⇒ 颜色与源一致,可直接用于正片。
    • 只有 2x 原生权重:选 3x / 4x 时仍按原生 2x 跑一遍、再把成片缩放到目标尺寸;推荐用 2x。
    • 没有 ONNX 权重:走「稳定引擎(ONNX)」的机器(50 系 / 兼容模式)用不到它们,软件会明确说明本批按另一支官方模型处理,不会闷声换模型。
  • 视频页「超分模型」下拉按速度与体积重排: 顺序变了,但你以前保存的模型选择会自动对应到新顺序上的同一个模型,不用重选。
  • 界面标签统一简写,修掉部分下拉文字被裁切:以前把模型名 + 体积 + 耗时塞在一行,窗口窄了会截断。
  • 视频新增「边缘增强」后处理:只加强明确边缘,用阈值把平坦区与噪点保护起来。 实测游戏素材:强边缘对比度 +11%,过冲仅上升 0.35 个百分点。 默认值随所选超分模型给(animevideov3 = 30,其它模型 = 60)。
  • 修复「指定帧率」下临时空间被算少一半(长视频会跑到一半爆盘、后段满是灰帧): 用「指定帧率」时,软件会按目标帧率把补帧倍率自动抬高(比如你选 2x,它抬到 4x), 但“要占多少临时空间”这笔账以前是在开工前按你选的 2x 算的 —— 倍率翻一倍、要占的地方也翻一倍,于是空间被算少近一半: 检查以为够就放行,跑到一半临时盘满,后半段中间帧写成残帧,只能拿深灰占位帧顶上(帧号连续、内容是废的)。 现在改成倍率定稿后按最终倍率把账重算一遍、再判一次空间,不够就在开跑前拦下并告诉你需要多少 GB。 只改“拦人时怎么算账”,画质与处理结果不受影响。
  • 8GB 显卡的超分提速约 1.6 倍: 以前 8GB 显存会被判成“只够单路”,根因是个 3 MB 的换算零头 —— 8GB 卡实际报 8188 MiB, 换算成 7.996 GB 再 ×0.75 = 5.997,与门槛 6.0 只差 0.003,于是整张卡掉回单路。 现在恢复两路并行:同一批素材实测 单路 3.66 帧/秒 → 两路 5.97 帧/秒(1.63 倍),输出逐帧检查无黑帧。 (6GB 卡仍是单路,不受影响;想看自己机器跑了几路,可看日志里的「并发路数」。)
  • 超分遇到黑帧不再“整批重跑”: 以前某个批次里只要有一帧被判黑,就把整批作废、换引擎重跑整批 —— 真机上这一跑能到二十多分钟, 而且重跑仍黑时整批退回未超分的源帧(那一段画质整体掉档)。 现在只重跑被判黑的那几帧(同批好帧保留),并给重跑加硬预算(最长几分钟), 到点就停、只把没救回来的帧退回源帧;零星 1 帧黑也不会再让后面的批次全部改用慢引擎。
  • 修掉「指定帧率」链路上的三处静默错误:
    • 切点判据只算一次、两条路共用(以前“普通分段”与“按真实时间戳排帧”各算一次 = 同一份判据两次全片解码, 而且其中一条路无视「转场识别」开关 —— 你明明没勾,它照样做切点保护);
    • 「按真实时间戳排帧」只在源确实是可变帧率(VFR)时生效,固定帧率的素材走常规处理;
    • 「去重」+「指定帧率」同时开时不再丢掉原片节奏(以前输出帧会按目标帧率均匀铺开: 该停的地方被快进、该快的地方被拉慢,总时长不变,但你会觉得“内容好像丢了”)。
  • 指定帧率导出的文件名直接写帧率: 以前是「…_补帧2x(自动3x)_rife413_60fps.mp4」这种重复三段的样子,现在就是「…_补帧60fps_rife413.mp4」。
  • 音频页的「强制结束」改成红色:与视频 / 抠图 / 图片页一致 —— 以前只有它是灰的,看着不像能停任务的按钮。
  • 诊断日志补强(只写日志文件,不往界面刷): 超分阶段每批记录「引擎 ms/帧 + 落盘 ms/帧 + 实际引擎参数 + 并发路数」,阶段末尾记录 GPU 利用率区间 —— 以后“怎么变慢了”看这两行就能定性:利用率长期只有六七成 ⇒ GPU 没吃饱;95%+ ⇒ 就是 GPU 算力这一层。
  • 修官网「AI 抠图」演示图被容器裁切的问题:现在完整显示。

v1.3.6 2026-09-13 · 预设模型调整 + 补帧倍率显示修复

预设模型调整与补帧倍率显示修复
  • 官方预设「通用画质增强 不含补帧」的超分模型换成 realesr-animevideov3(与「动漫通用」同款)。 该预设基线升到 Rev 5,升级后会自动刷新这一条;你自己另存的预设不动。
  • 修「去重补帧4x」预设摘要显示成 2x(实际任何倍率都可能显示错一档):以前打印的是下拉序号而不是倍率。 现在序号与倍率收敛成一份映射(0/1/2/3/4/5 = 2x/3x/4x/8x/12x/16x),并补了单元测试。
  • 16x 补帧现在也会提示「高倍率」:以前判断条件漏了 16x,已改为按倍率判定(≥8x)。

本版不改变处理结果:同样的设置下,输出与 v1.3.5 一致,修的是“显示与实跑对不上”。

v1.3.5 2026-09-12 · 补帧引擎重编 + 界面稳定性 + 全面自检修复

建议所有用户更新:修复界面卡死,50 系补帧不再依赖驱动更新
  • 补帧引擎重编:用与实拍超分同一套 2025 / 2026 版 ncnn 源码重编 RIFE,50 系与较新驱动不再“只能等驱动修复”。 输出数值等价(肉眼无差),速度略快。
  • “开了去重就卡死”从根上修好:卡住的是界面,后台任务其实一直在跑。日志区滚动条改常驻、去掉高度动画。
  • 自愈兜底:万一还有别的成因,检出布局循环就自动停用界面日志刷新(日志继续写文件,任务照常跑完)。
  • 引擎被挂死时不再永久卡住:看门狗强制终止后的等待加了 5 秒上限,收不回来就明确失败并提示重启。
  • 显存不足的“自动降分块”以前是空转:现在真的按 自动 → 512 → 256 → 128 降档重试。
  • 修“点一次停止就永久变慢”:取消不再被误判成硬件编码损坏(以前会永久拉黑硬编,之后全走 CPU)。
  • 备用 ffmpeg 缺失会明确预警:以前缺了会静默变慢且日志没线索。
  • 去重分析全程可见、随时可停:现在有逐帧进度与日志心跳;开去重时的默认档改为「智能检测」。
  • 预设两处 bug 修复:切换排序后点「应用预设」会套用另一条;自建同名预设会被官方基线整份覆盖(现在只标记为官方)。
  • 预设文件损坏不再静默覆盖你的数据(先备份 .bak + 本次运行只读保护);音频页「记住上次参数」以前永远失效,已修。
  • 广告开关改为「本次运行不显示广告」:默认不勾,只对本次运行生效,重启恢复显示。
  • 老 GTX 分档改准:GTX 10 系(Pascal)与 GTX 600/700/800/900 系分开,10 系用 ncnn-Vulkan 完全可用。
  • 「检测兼容性」不再用小图糊弄自己:改走与处理流水线相同的入口(生产帧尺寸 + 真实模型)。
  • 视频页超分模型下拉调整:轻量通用模型(realesr-general-x4v3,5 MB)上移、耗时档改「中」;已保存的选择会自动换算。

⚠ 需要你动手的一处:图片后处理有六个锐化类档位各自换了机理, 「减少杂色」由两档改为连续力度,「去雾」「边缘增强」强度重新定标。 预设里存的是数值 —— 数值没变、效果和以前不一样,请在图片页重新调一次并另存。 附带的好消息:4K 导出提速约 19 倍。

v1.3.3 2026-09-08 · 稳定性 / 兼容性 / 速度增强

修复一批隐性缺陷,并提升视频处理速度
  • 探测看门狗(治“处理卡死只能强杀”):开始处理前会用 ffmpeg 完整扫一遍视频,这一步以前没有超时保护。 现在启动静默 90 秒 / 运行静默 120 秒会自动掐掉并提示。
  • 修 x4plus 系超分输出全黑帧:个别卡(尤其 RTX 50 系新驱动)会静默输出全黑帧,根源是引擎线程档位过高,现封顶 6。
  • 回退帧统一缩放,治花屏:超分失败回退原帧时先统一尺寸再写入,避免混入异尺寸帧导致成片花屏。
  • 硬编探测修复:以前只编 1 帧就被判“无效”而静默禁用;现在会多编几帧。
  • 视频超分提速(相同帧只超分一次):内容完全一样的帧按哈希去重,只算一次、其余复用结果 —— 无损提速。
  • 预计时间更准(四个阶段都有 ETA):每阶段用各自的净耗时时钟。
  • GPU 识别修正(治“有独显却走 CPU”):修复注册表枚举与引擎枚举编号错位的问题。
  • 不轻易掉 CPU,掉的时候明确提示:GPU 可用性探测改为 3 次重试 + 更宽松的超时;真降级会提示“速度会变得特别慢”。
  • 排查手段加强:超分 / 编码实际走的设备全部记进诊断包。
  • 赞赏提示更克制(冷却 10 小时)。

v1.3.2 2026-09-07 · 视频稳定性加固 + 补帧降级链 + 设备识别修复

重点修复黑帧、黑屏、补帧残缺与显卡误判
  • 兼容模式对 NVIDIA 卡也走 ONNX:避开 ncnn-Vulkan 偶发黑帧;检测到黑帧后后续批次直接改用 ONNX。
  • 编码器不再优先用不可靠的 QSV:仅在无其它可用硬编时兜底;探测分辨率从 320×240 提到 1280×720。
  • 补帧降级链:失败 / 黑帧 / 0 帧时按「显卡 → ONNX(DirectML)→ 换卡」降级,不会静默掉到慢速 CPU。
  • 修复独显被误判成 CPU:显卡编号稀疏时会被当成无效设备,现已按引擎设备表判断。
  • Real-ESRGAN 探测超时放宽 5 秒 → 15 秒,并显示“正在检测显卡兼容性”,冷启动慢的卡不再被误判成卡死。
  • 视频帧转 JPG 直接走 GDI,更快更可靠。
  • 参数记忆修复:码率 / 格式 / 编码等下拉的“记住上次”恢复生效;补帧倍率 12x / 16x 也能被记住。
  • 新版本提示改回顶部横幅(不弹窗打断),点 ✕ 本次不再显示。

v1.3.0 2026-09-05 · 自检驱动 + 始终用显卡 + 稳定性

新增启动自检;优先使用显卡;兼容模式与看门狗按设备档次自适应
  • 启动自检(全新):首次启动或版本更新后弹出自检,逐项检测显卡 / 显存 · 驱动 · 内存 · CPU / 引擎 / 各功能模型, 全通过后显示报告,点「确定」进主界面。
  • 始终用显卡:通用引擎的降级链去掉“GPU → CPU”;计算设备下拉移除 CPU 选项,默认取自检实测的最佳独显。 核显只作兜底。
  • 大显存机型吃满显卡:ONNX 超分分块自适应(512 → 768)+ 3 路并行。
  • 兼容模式加强:自动降低分块与批大小防止爆显存,对风险显卡强制走 ONNX 稳定路线。
  • 黄字提醒更全:黑帧降级、显存不足降分块、高倍率补帧、走 ONNX、临时盘紧张等都会提示。
  • 源兼容:HDR / 广色域源自动转 BT.709 SDR;超大图加入尺寸与内存保护;MKV 无损音轨不再被强制转 AAC; 分辨率超 4K 或帧率超 240 会给出提示。

已知限制

  • 音频 AI 分离优先用显卡(DirectML);无显卡或驱动不兼容时用 CPU,约 1.5 分钟 / 分钟音频。
  • 音频「升采样率」只对低采样率源(8k / 16k / 22k / 32k)有效;44.1 kHz 音乐已是全频带,改用「增强」。
  • 视频超分 / 补帧在老电脑上慢是物理限制,建议从 waifu2x 与 1x~2x 倍率起步。
  • AI 抠图固定用 CPU(避免占满显卡导致整机卡顿),图片多时要耐心等。
