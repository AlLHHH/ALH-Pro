更新日志

最新版本 v1.3.6,发布于 2026-09-13。点击各版本可展开细节。升级方式: 直接覆盖安装,无需卸载,也不必重新下载模型。

阅读说明: 凡是会影响已有设置或需要重新调整参数的改动,都会单独标注;本版未变更的部分也会一并说明。

v1.3.6 2026-09-13 · 预设模型调整 + 补帧倍率显示修复

本版改动:预设模型调整与补帧倍率显示修复
  • 官方预设「通用画质增强 不含补帧」的超分模型换成 realesr-animevideov3(与「动漫通用」同款)。 原模型是自转的 realesr-general-x4v3,摘要里还印着旧标签「(轻量)」,现在下拉里显示的名称已统一。 该预设基线提升到 Rev 5,升级后会自动刷新这一条;你自己另存的预设一律不动。
  • 修「去重补帧4x」预设摘要显示成 2x(实际上任何补帧倍率都可能显示错一档): 摘要里打印的是下拉【序号】(0~5)而不是倍率,序号 2(真值 4x)显示成 “2x”,序号 0(真值 2x)更会显示成 “0x”, 会让人以为自己选错了档。现在序号与倍率收敛成一份映射(序号 0/1/2/3/4/5 = 2x/3x/4x/8x/12x/16x), 预设摘要、耗时预估、输出规格全部走这份映射,并补了单元测试钉住这类抄写事故。
  • 16x 补帧现在也会提示「高倍率」:此前判断高倍率的条件漏了 16x,最高倍率反而没有耗时提示,已改为按倍率判定(≥8x)。

本版不改变实际处理结果:同样的设置下,输出与 v1.3.5 完全一致,修的是“显示与实跑对不上”。

v1.3.5 2026-09-12 · 补帧引擎重编 + 界面稳定性 + 全面自检修复

建议所有用户更新:修复界面卡死,50 系补帧不再依赖驱动更新
  • 补帧引擎重编:用与实拍超分同一套 2025 / 2026 版 ncnn 源码重新编译 RIFE, 50 系与较新驱动不再“只能等驱动修复”。输出与旧引擎数值等价(1080p PSNR 76.9 dB、4K 82.1 dB,肉眼无差),速度略快(1080p 3.03 秒 → 2.94 秒)。
  • “开了去重就卡死”的真因已从根上修:日志区滚动条与自动折行互掐造成界面布局循环 —— 卡住的是界面,后台任务其实一直在正常跑。四页日志区的滚动条改为常驻、去掉面板高度动画、滚动改到下一帧执行。
  • 自愈兜底:万一还有别的成因,一旦检出布局循环会自动停用界面日志刷新(日志继续写文件、任务照常跑完), 不会再出现“界面死了只能重启、把任务一起打断”。
  • 引擎被挂死时不再永久卡住:看门狗强制终止后的“等管道结束”加了 5 秒上限,收不回来就明确失败并提示重启。
  • 显存不足的“自动降分块”以前是空转(日志写着降档、参数一字没改、只是白跑 3 次),现在真的按 auto → 512 → 256 → 128 降档重试。
  • 修“点一次停止就永久变慢”:取消不再被误判成硬件编码损坏(此前会在本次运行内永久拉黑硬编,之后全走 CPU 软编)。
  • 备用 ffmpeg 缺失会明确预警:驱动较旧的机器靠它兜底,缺了会静默变慢且日志毫无线索,现在会直接提示。
  • 去重分析全程可见、随时可停:「帧差 + SSIM」这条路径此前既不报进度也不响应停止,现在有逐帧进度与日志心跳,点停止立即中断。开去重时的默认档改为「智能检测」。
  • 预设两处 bug 修复:把列表切成“按名字 / 按最近修改”后点「应用预设」会套用另一条; 自建的同名预设会被官方基线整份覆盖(现在只标记为官方,参数一个字不动)。
  • 预设文件损坏不再静默覆盖你的数据(先备份 .bak + 本次运行只读保护);音频页「记住上次参数」以前永远失效,已修。
  • 设置里的广告开关改为「本次运行不显示广告」:默认不勾,只对本次运行生效,重启自动恢复显示(仍然没有永久关闭广告的开关)。
  • 老 GTX 分档改准:GTX 10 系(Pascal)与 GTX 600/700/800/900 系分开 —— GTX 10 系用 ncnn-Vulkan 完全可用,不再一律劝退。
  • 「检测兼容性」不再用小图糊弄自己:改走与处理流水线完全相同的入口(生产帧尺寸 + 真实模型 + 结论缓存), 不会再出现“小图检测通过、真跑起来才出问题”。
  • 视频页超分模型下拉调整:轻量通用模型(realesr-general-x4v3,5 MB)上移到「超慢」之前、耗时档改「中」;已保存的模型选择会自动换算,不会静默变成超慢。

⚠ 需要你动手的一处:图片后处理有六个锐化类档位各自换了机理(不再是一个旋钮拧六遍), 「减少杂色」由两档改为连续力度,「去雾」「边缘增强」强度重新定标。 预设里存的是数值 —— 数值没变、效果和以前不一样,请在图片页重新调一次并另存。 附带的好消息:4K 导出提速约 19 倍(「边缘抗锯齿」换成软件自己的实现,实测 4.88 秒/帧 → 0.26 秒/帧)。

v1.3.3 2026-09-08 · 稳定性 / 兼容性 / 速度增强

修复一批隐性缺陷,并提升视频处理速度
  • 探测看门狗(治“处理卡死只能强杀”):开始处理前会用 ffmpeg 完整扫一遍视频(查转场 / 可变帧率 / 色彩空间), 这一步以前没有超时保护、连「停止」都停不下来。现在加了看门狗(启动静默 90 秒 / 运行静默 120 秒自动掐掉并提示)。
  • 修 x4plus 系超分输出全黑帧:个别卡(尤其 RTX 50 系新驱动)用 realesrgan-x4plus 时会静默输出全黑帧(退出码 0、毫无报错), 根源是引擎线程档位过高,现封顶 8 → 6。
  • 回退帧统一缩放,治“看不出但真的翻车的花屏”:超分失败回退原帧时先统一尺寸再写入,避免混入异尺寸帧导致 ffmpeg 静默产出花屏成片。
  • 硬编探测修复:硬件编码探测以前只编 1 帧就被判“无效”而静默禁用,导致明明有硬编却一直走更慢的 CPU 软编;现在会多编几帧(≥5)。
  • 视频超分提速(相同帧只超分一次):视频里内容完全一样的帧(录屏静止画面、动漫一拍二/一拍三)按内容哈希去重, 相同帧只算一次、其余直接复用结果 —— 无损提速,输出与逐帧超分完全一致,静止素材越多省得越多。
  • 预计时间更准(四个阶段都有 ETA):修正了“一个时钟被超分独用”的根因(以前把拆帧 / 去重 / 补帧的耗时也计入超分速率); 现在每阶段用各自的净耗时时钟(扣除休息与暂停)。
  • GPU 识别修正(治“有独显却走 CPU / 走错路”):修复「注册表枚举」与「引擎枚举」编号可能错位的问题 (双卡 AMD 核显 + NVIDIA 独显的机器上尤其明显),以及专业卡被误判成 50 系的风险。
  • 不轻易掉 CPU,掉的时候明确提示:GPU 可用性探测改为 3 次重试 + 更宽松的超时,一次驱动抽风不再把独显判成不可用; 万一真的降到 CPU,会明确提示“速度会变得特别慢”。
  • 排查手段加强:超分 / 编码实际走的是什么设备(ncnn-GPU / ONNX-DirectML / ONNX-CPU)全部记进诊断包, 自检结论与诊断包也一并加强。
  • 赞赏提示更克制(冷却调整为 10 小时,且只有认真看了赞赏码才触发)。

v1.3.2 2026-09-07 · 视频稳定性加固 + 补帧降级链 + 设备识别修复

重点修复黑帧、黑屏、补帧残缺与显卡误判
  • 兼容模式对 NVIDIA 卡也走 ONNX:视频超分勾选「兼容模式」后(无论是否 N 卡)直接用 ONNX DirectML 稳定引擎, 避开 ncnn-Vulkan 偶发黑帧;检测到黑帧后本次视频后续批次不再重跑 ncnn,直接改用 ONNX。
  • 编码器不再优先用不可靠的 QSV:Intel 核显硬编在“独显 + 核显”双卡机上容易输出无效文件,现在仅在无其它可用硬编时兜底; 编码器探测分辨率也从 320×240 提高到 1280×720。
  • 补帧降级链:固定使用选定的独立显卡,失败 / 黑帧 / 0 帧时按「显卡 → ONNX(DirectML)→ 换卡」降级, 不静默掉到慢速 CPU;并新增“输出帧数远少于目标帧数即触发降级”,防止把残缺当成功。
  • 修复独显被误判成 CPU:显卡编号稀疏(如 1、2)时会被错误当成无效设备,导致“明明有独显却报无独显 / 走 CPU”,现已按引擎设备表判断。
  • Real-ESRGAN 探测超时放宽 5 秒 → 15 秒,并在探测时显示“正在检测显卡兼容性(约 15 秒)…”,冷启动慢的卡不再被误判为卡死。
  • 视频帧转 JPG 直接走 GDI,不再刷“WinRT JPG 编码不可用”的日志,更快更可靠。
  • 与视频页参数记忆相关的修复:码率 / 格式 / 编码等下拉的“记住上次”恢复生效;补帧倍率 12x / 16x 也能被正确记住。
  • 新版本提示改回顶部横幅(不再弹窗打断),点「去下载 / 网盘下载」跳转,点 ✕ 本次不再显示。

版本提示更醒目;界面提示与广告改为随机轮播

v1.3.0 2026-09-05 · 自检驱动 + 始终用显卡 + 稳定性

新增启动自检;优先使用显卡;兼容模式与看门狗按设备档次自适应
  • 启动自检(全新):首次启动或版本更新后弹出设备自检,逐项检测(显卡 / 显存·驱动·内存·CPU / 最佳独显 / 可用性 / DirectML·ONNX 超分 / 超分补帧引擎 / 各功能模型),全部通过后显示正式自检报告,点「确定」才进主界面。 报告里功能与引擎逐项用 ✓ / ✗ 标注,设置页可「重新检测」「打开引擎目录」。
  • 始终用显卡:通用引擎的降级链去掉“GPU → CPU”(失败改为明确报错并给出建议); 计算设备下拉移除 CPU 选项,默认取自检实测出的最佳独显;你手动选定的有效独显不会被覆盖。 核显只作为“底牌”兜底(仅当独显全部不可用时),并会黄色提示处理变慢。
  • 大显存机型吃满显卡:ONNX 超分分块显存自适应(512 → 768)+ 3 路并行,GPU 占用与速度显著提升。
  • 兼容模式加强:自动降低分块与批大小防止爆显存卡死,对风险显卡强制走 ONNX 稳定路线,同时尊重你选择的倍率、不乱降。
  • 黄字提醒更全:黑帧降级、显存不足自动降分块、高倍率补帧(4x+)、走 ONNX、临时盘紧张等都会提示,让你知道“为什么慢 / 在重试 / 不是卡死”。
  • 源兼容:HDR / 广色域源自动转 BT.709 SDR(避免偏色与信息丢失);超大图加入尺寸与内存保护(不再 OOM); MKV 无损音轨不再被强制转 AAC;视频分辨率超 4K 或帧率超 240 时给出黄色提示。

v1.0.0 首个正式版

图片超分、AI 抠图、视频超分 / 补帧 / 去重的首个完整版本

从早期的 v0.3 / v0.5 预览版迭代而来:v1.0 起把「图片放大、AI 抠图、视频处理」整合到统一界面, 并在后续版本中逐步加入批量管理、去重复帧、音频处理与设备自检。 各版本的软件包与发布记录见公开仓库的发布页。

已知限制

  • 音频 AI 分离优先用显卡(DirectML)加速;无显卡或驱动不兼容时用 CPU,约 1.5 分钟 / 分钟音频。
  • 音频“升采样率”只对低采样率源(8k / 16k / 22k / 32k)真的有效;44.1 kHz 音乐本身已是全频带,无需升采样,请改用「增强」。
  • 视频超分 / 补帧在老电脑上慢是物理限制,建议用 waifu2x 与 1x~2x 倍率起步。
  • AI 抠图固定使用 CPU(避免占满显卡导致整机卡顿),图片多时需要耐心等待。
