开始前的准备

  1. 左侧导航是四个页面:图片放大 / AI 抠图 / 视频处理 / 音频处理,各管各的。
  2. 页面左边是设置、右边是结果区;参数改完即时生效,先调好再点「开始处理」。
  3. 计算设备一般不用管:启动时自动检测,有独显且引擎兼容就自动用上;不兼容会自动走兼容路线,只是速度有差异。

抠图模型安装

抠图 = 去掉背景、只留主体。安装包不含 AI 抠图模型(模型单独打包,约 1.4 GB);没装时「AI 抠图」页会显示黄色提示。

方式一(推荐):装软件时在「选择附加任务」页勾选「下载并安装模型包」,安装程序会自动下好。

方式二(下载失败或已装完软件):下载 models_v1.0.zip(内含中文说明),解压到:

程序目录\engines\rembg\
    birefnet-lite.onnx
    birefnet.onnx
    isnet-general-use.onnx
    isnet-anime.onnx
    u2net.onnx
    u2netp.onnx
  • 程序目录怎么找:右键桌面「ALH Pro」图标 →「打开文件所在位置」(默认 C:\Users\用户名\AppData\Local\Programs\ALH Pro)。
  • 6 个 .onnx 直接放进 rembg 目录,不要再套一层文件夹。
  • 装好的标志:AI 抠图页左上角的黄色提示消失。
  • 嫌麻烦就直接用完整版,装完所有功能立即可用。

图片放大

图片放大 = 把一张图变清晰或变大。流程:添加图片 → 选算法 → 选倍数 → 开始处理。

第 1 步:添加图片

  • 点「添加图片(可多选)」或直接把文件拖进来,支持 PNG / JPG / WebP / BMP,可批量;
  • 列表里选中哪张,预览和参数就只针对那一张。

第 2 步:选择算法

素材类型选哪个
动漫 / 插画 / 二次元动漫插画(waifu2x)
照片 / 实拍 / 人像真实照片(Real-ESRGAN)

选错会怎样: 动漫图用 Real-ESRGAN 会发糊,照片用 waifu2x 会像画。先用单张各试一次再批量。

waifu2x 下面还有两个模型:

  • cunet(通用):画质优先;
  • upconv_7_anime(动漫插画):更快,适合线条简单的漫画。

第 3 步:选倍数

  • 1x 超分:2x 放大后缩回,只提升清晰度、不放大尺寸,最常用;
  • 2x / 3x / 4x:直接放大。列表里灰色项表示当前模型不支持。

第 4 步:降噪

  • 降噪级别:不降噪 / 弱 / 中 / 强。图上有压缩块、噪点就开「中」;本身很干净就用「不降噪」;
  • 素材没有噪点时,强档反而会磨掉细节,建议从「关 / 弱」开始试;
  • 照片模式另有「预处理降噪」:噪点多时勾上,强度选弱~中,太强线条会糊。

第 5 步:高级选项

默认不用调。画面发灰试「清晰」,发虚试「去模糊」,有锯齿试「边缘抗锯齿」;一次只加一项,确认有效再叠加。

结果

  • 输出目录默认与源图同目录(可以改);
  • 多张图会自动建子文件夹,不用管;
  • 格式默认 JPG,要去背景选 PNG;JPG 质量 85~95 就够,再高只是文件更大。

AI 抠图

抠图 = 去掉背景、只留主体(背景变透明)。流程:添加图片 → 选模型 → 微调 → 预览 → 保存。

第 1 步:添加图片

在「输入」下选图,支持多张批量。

第 2 步:选模型

用途选哪个
第一次用,不知道该选啥BiRefNet 高精度(默认推荐)
背景复杂、画面里有多个主体BiRefNet 完整版
人像 / 产品,边缘要干净ISNet 精细边缘
动漫插画ISNet 动漫
背景简单、要速度快U²-Net 通用
要最快、批量很多U²-Net 轻量

AI 抠图固定用 CPU 计算(避免占满显卡导致整机卡顿),批量处理时耗时会长一些。

第 3 步:参数微调

  • 前景 / 背景阈值:主体与背景颜色接近时,降低前景阈值、提高背景阈值;拿不准就勾「自适应阈值」;
  • 边缘羽化:数值越大边缘越柔和,适合抠毛发与半透明边缘;
  • 边缘增强(抠图):主体边缘毛糙、发虚时提高。它管的是蒙版边缘,和视频页同名的那个不是一回事(见 视频处理 · 可选后处理);
  • 边缘清理:边缘有碎点、杂色时开启。

第 4 步:查看效果

右侧预览区处理完就能看;按住「查看原图」可以对比前后。彩色预览 = 原图 × 蒙版,棋盘格 = 透明区域。

结果

保存到输出目录(默认与源图同目录,多张自动分子文件夹)。要透明背景记得选 PNG。

视频处理:超分、补帧与去重

超分让画面更清晰,补帧让动作更流畅,去重删掉重复帧。流程:添加视频 → 勾处理项 → 设参数 → 开始。

注意:「超分」与「补帧」至少勾一项才能开始;只做去重要连补帧一起勾。

第 1 步:添加视频

拖入或点列表添加,支持 MP4 / MKV / MOV / WebM 与批量。每个视频可单独裁剪、单独设帧率。

第 2 步:视频超分

素材引擎
老动画 / 低清动漫经典动漫(waifu2x,最快)
真人 / 实拍通用(Real-ESRGAN)
  • 倍数:1x 只提升清晰度、不改尺寸,建议先试;1.5x / 2x 以上为放大,也可填「自定义分辨率」。
  • 倍率越高越慢、越吃显存;笔记本或较旧的显卡先用 1x~2x 试一小段。

第 3 步:补帧

补帧 = 在原有帧之间生成中间帧,让动作变流畅。动漫 24fps 补到 60fps、电视 25/30fps 补到 60fps 都是常见用法。

  • 模型:默认「通用画质最新(RIFE v4.13)」就行;老素材结果不正常时,换别的档位再试。
  • 帧率:默认「各视频默认帧率」,按每个视频自己的原始帧率处理,什么都不用设。要统一成 60fps 就选「单独调整各视频帧率」并填 60;要降帧率就选「帧率偏移」。
  • 输出倍率:输出帧率 = 原帧率 × 倍率(默认自动,也能直接手填 60)。倍率可 2x / 3x / 4x / 8x / 12x / 16x,8x 以上会提示「高倍率」,耗时与占用明显上升。
  • 可变帧率:默认「自动」;录屏、手机、监控这类帧率不均匀的素材会自动按原节奏处理。

第 4 步:去除重复帧

去重 = 删掉静止与重复的画面,只留真实内容帧,补帧更准、文件更小。

  • 智能检测(默认):自动估节奏,不用管。策略有均衡(推荐)、激进(删得多)与保守(几乎不误删);
  • 动漫模式:确认片源是一拍二 / 三 / 四时选对应档位;
  • 手动模式:高级用户用,默认别碰;
  • 建议勾上相位自动对齐,防止抽到中间帧。

去重 + 补帧后的输出时长和源一样,帧率 = 内容帧率 × 补帧倍率。

第 5 步:输出

  • 码率:自动(推荐);不满意再试 中 / 高,「极高」文件很大;
  • 格式:MP4(通用,推荐);MKV 老播放器可能不认;
  • 编码:H.264(通用)做默认;H.265 同画质文件小一半,但老设备可能播不了;
  • 静音:只要画面时勾上。

兼容模式

勾上会降低显存占用,避免显存不足或卡死,画质基本不变。没有独显、显存小或处理不稳定时勾上,其它情况不用开。

可选后处理

  • 果冻修复:给补帧产生的画面扭曲叠一层真实运动模糊,动作更自然;
  • 光流调整:果冻多就调低,动作卡就调高;
  • 转场识别:镜头切换处不插帧,避免鬼影;
  • 边缘增强(视频):超分之后把明确边缘的对比提一点,线条更「坐得住」。它只用阈值保护平坦区与噪点,不会把噪点一起提上去。 默认随所选超分模型给(animevideov3 = 30,其它模型 = 60);觉得画面发「锐」就调低或关掉。

两个「边缘增强」别弄混:抠图页那个修的是蒙版边缘(白边、碎点),视频页这个提的是画面本身的边缘对比。

音频处理

音频处理 = 升采样率、增强、人声 / 伴奏分离、降噪。流程:添加音频 → 勾处理项 → 开始,支持批量。

AI 升采样率

电话录音、老磁带这类 8k / 16k / 22k / 32k 的低采样率音频,AI 会补出缺失的高频并升到 48kHz,听起来更清楚。 44.1k 以上的正常音乐已是全频带,软件会自动跳过,不报错。

增强

优化人声,咬字更清晰、层次更好。强度有关、柔和(推荐)、标准与强力四档;只作用于最终输出,不单独生成文件。

AI 分离:人声与伴奏

用神经网络把人声和伴奏拆开,可多选:

  • 提取人声:只要歌声(去掉伴奏);
  • 去人声(卡拉OK伴奏):只要伴奏(去掉歌声);
  • 分离:导出人声 + 伴奏两个文件;
  • 自定义组合:勾选要输出的轨道(人声 / 伴奏 / 其他 1 / 其他 2),每轨音量 0~200%,适合混音。

分离优先用显卡加速(DirectML);没有可用显卡就用 CPU,一首歌几分钟到十几分钟。

降噪

  • 用于录制的音频:去掉底噪、电流声与压缩噪点;
  • 选项:关 / 弱(推荐)/ 中 / 强(可能有损失);
  • 已混音完成的音乐不建议用强档,会损失细节。

音色调整

  • 响度归一(音量统一):多首音量忽大忽小时勾上,听感更稳;
  • 低切(去低频隆隆声):去掉低频轰鸣 / 底噪;
  • 清晰增强(高频微调):让人声 / 乐器更明亮。

预览与裁剪

  • 列表里双击 → 展开波形,可播放试听;
  • 拖波形两端的把手 → 只处理选中的时间段。

输出格式选择

场景建议
图片要给别人看 / 上传JPG,质量 85~95
图片要去背景、要透明PNG
视频要在手机 / 电视 / 平台上放MP4 + H.264,码率自动
视频想同画质但文件更小MKV(或 MP4)+ H.265,注意老设备可能播不了
音频要在手机上听MP3(兼容性最好)
音频要再编辑 / 存档WAV 或 FLAC(无损)

输出默认与源文件同目录,批量会自动建子文件夹,不会覆盖原文件。

效率建议

  1. 先用一小段样片试跑。截 5~10 秒,确认模型与倍率再整段处理,少返工。
  2. 动漫片源先开去重再补帧。重复帧去干净,补帧更准、文件更小。
  3. 较旧的电脑从 1x 超分 / 2x 补帧起步。倍率越高,代价越大。
  4. 留意状态栏与日志。会写明用显卡还是 CPU、是否降级、预计剩余时间。
  5. 处理重要素材前先备份原文件,并留意临时磁盘空间。
