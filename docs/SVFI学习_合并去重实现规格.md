# SVFI 学习 -> 合并去重实现规格(待用户确认)

> 依据:桌面《SVFI深度学习记录.txt》第8部分 Round2 仿真结论(R2-1/2/3)。
> 原则:组件学自 SVFI(GroupDetect 骨架),但为独立实现;
> 所有阈值先在 `_dedup_sim` 离线标定后进产品;默认档位变更须用户确认。

## 目标
把 ALHPro 的"分段内容帧率化"去重从单一三闸,升级为:

```
删除 = 组判定标记(G) ∩ 三闸安全集(Safe)
```

- 三闸安全集:保证"绝不误删微动/口型"(== 现行安全底线);
- 组判定标记:识别"近似保持段"(== SVFI 拍N 检测能力,覆盖像素级相同之外的保持段);
- 二者之交 = 只删"既符合节奏模式、又像素级安全"的帧。

## 数据结构(段内已有/新增)
| 数组 | 含义 | 现状 |
|---|---|---|
| sads16[] | 相邻对 16px 点采样 SAD | ✅ 已有 |
| ssims4[] | 相邻对 4px 分块 SSIM | ✅ 已有 |
| maxds[] | 相邻对全分辨率 32x32 块最大差 | ✅ 已有 |
| histDiffs[] | 相邻对"蓝通道::4 + 均衡 + absdiff 均值"(SVFI get_norm_img_diff) | ➕ 新增(逐帧一次性均衡缓存,成本≈maxD32 的 1/3) |

## 算法流程(替换现"节拍确认+删除集"两段)
1. **Pass1(档位开关)**:阈值 th1:
   - 保守档(默认,面向真人/混合):th1 = 0.001(== SVFI 全等级);
   - 动漫档:th1 = 0.3(附组判定);
   流式等价:帧 f 与"上一保留帧"的 histDiff < th1 → 不保留(直接视为已删)。
2. **组判定**:q ∈ [4, maxQ](maxQ = 4+档位拍N 减 1;智能档默认 6,即拍到拍四);
   判据:d1 < d0 且 d1 < d2;d(a,b) = histDiff(或 maxD)沿帧号的路径和;
   count == (q(q-5)+6)/2 → 命中,标记组内中间 q-3 帧;滑窗继续。
3. **安全集 Safe**:f∈[s+1, e-2] 且 sads16[f-1]≤0.3 && ssims4[f-1]>=0.999 && maxds[f-1]<=1.0。
4. **删除集 = G ∩ Safe**(现"节拍确认"逻辑仅保留为真人档的补充通道,默认关闭)。
5. **保护**:首末帧、转场帧、整段保留率下限(在 sim 标定:默认"删除后保留 ≥ 35%",
   否则整段原样保留——防组判定在非动画素材上失控)。
6. **日志**增加:`组判定标记 {G}/{N}、安全集 {Safe}、删除 {del}、保护复核 {X}`。

## 验收口径(每轮必测,沿用已建compare_outputs.ps1)
跳步率<=1%、口型保留(护栏计数=0 删)、误删率(与 dedup_sim 对照)、时长/帧率误差。
