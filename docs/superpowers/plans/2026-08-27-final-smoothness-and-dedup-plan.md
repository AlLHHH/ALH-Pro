# ALH Pro 补帧/去重「真正流畅」最终实现方案（含已做改动与验证）

> 说明：本方案基于对 `VideoService.cs` 的实测研究（素材1 = 连续运动、无真定格、过删致卡）+ 参考专业做法（整段一次 RIFE + 运动补偿去重）。已确认/已改/待改如下。

## 一、根因与正确做法（实测驱动）

**素材1 实测：**
- 相邻帧 SSIM 0.86~0.99（无 >0.99 真重复帧）；对齐残差 `8.4, 19.8, 9.1, 21.8, ... 2.26, 2.1, 6.26` → **只有 2 帧 <2.5**，绝大多数 5~26。
- 结论：素材1 是**连续运动**（背景+人物每帧都在动），**几乎没有可去重的"真定格"**。
- 用户导出"去重 38→10（删 50%）"的**过删**，来自旧的**低 SSIM 阈值（0.85~0.97）+ 静止段合并**把"相似但连续运动"的帧当重复删了 → 内容被压到 10.4fps → 补帧去桥大 gap → **卡**。

**正确做法（专业/已具备）：**
1. **整段一次 RIFE**（上下文足 → 光流准 → 不糊不扭），快（素材1 4x ≈ 10.66s、149帧）。
2. **镜头运动补偿去重**：先估相机整体平移并"对齐"，再在对齐残差上判断人物动没动 → 精准抓"背景 pan 下的人物定格"，不误删连续运动。
3. **去重只删"真定格"**（SSIM ≥0.995 或对齐残差极小），不再删"相似但连续运动"的帧。

## 二、已确认在代码里的（专业做法已具备）

- **整段一次 RIFE**：`ProcessVideoAsync` 方案 C（`fpsMode==2`，`FpsBaseCombo` 默认=2）走"密度还原 → 单次 RIFE"（`VideoService.cs` 约 L631-660）。
- **运动补偿去重**：`EstimateGlobalShift`（约 L2417）+ `DetectDupFramesWithSsim`（L1988-1992）+ `DetectDupFramesAdaptive`（L2228-2277）默认开启（`motionCompDedup` 默认 true，UI `DedupMotionComp` 默认 true）。
- **一键设置去重**：`VideoView.xaml.cs` L1399-1401（按分析重复率自动选 去重开/关 + 智能/动漫/标准 档位）。
- 已修的不流畅/健壮性 bug：暂停=冻结覆盖全部子进程+多路并发（`SuspendActiveProcess` 遍历 `App.ActiveProcesses.Snapshot()`）、智能去重内存滚动统计（L2204-2235，标量数组代替 byte[] 全量驻留）、`SampleGray` 用 `Clone(24bppRgb)` 容错（L2384）、setpts 段数上限 400（L1921）、删除死代码 `OtsuSadThreshold`。

## 三、本次新增改动（解决"过删致卡"——已编译通过）

`VideoService.cs` 两处：**把去重收紧为"只删真定格"**（对齐残差/SSIM≥0.995 判重，人物定格交给运动补偿判据）：

1. **主 SSIM 判重阈值**（约 L369-371）：`ssimThr = max(原值, 0.995)`。不再用 0.85~0.97 的低阈值删"相似但连续运动"帧。
2. **静止段合并阈值**（约 L390-396）：`segSsim = max(原值, 0.995)`。只合并"几乎完全相同"的段，不把连续运动并掉。

**效果**：素材1 去重只删约 2 帧（连续运动不再过删），内容帧率保持≈原，整段 4x → 149帧、丝滑、不卡。

**构建验证**：`dotnet build ImgUpscalerUI.csproj -c Release -p:Platform=x64` → 0 错误（12 个既有警告）。

## 四、建议的最终"一键智能"默认（UI 层，供另一会话/你来定）

目标：用户**只选视频 → 点「开始处理」→ 丝滑**，不用管模式/阈值/方案。

- **默认帧率对齐 = C（对齐丝滑/整段）**：已默认（`FpsBaseCombo` 0 → fpsMode 2）。
- **默认去重 = 智能（自适应）+ 运动补偿开 + 保守**：已默认；甚至可**默认去重关**（素材1 无真定格，不去重+整段插值已丝滑）。
- **隐藏/折叠高级项**：把 5 种去重模式、SSIM/SAD/保护/定格阈值、A/B/C、帧率三档收进"高级设置"，前台只留「开始处理 ＋ 智能」。
- 可选：加一个"**智能(推荐)**"大按钮，内部自动调 `DedupModelCombo`（按分析重复率，复用 L1399-1401 逻辑），一按即用。
