# 自研"任意时刻插帧 + 节奏重采样"方案(对标 SVFI,独立实现)

> 目标:对标 SVFI 的「时空重采样 / 交叉重建 / 前进消重 / 时空线性化」四功能的公共能力——
> **任意时刻(任意 t)插帧**,即帧对 (A,B) 间可在任意位置 φ∈[0,1] 生成中间帧。
> 全部使用自有引擎(rife-ncnn-vulkan)与自有实现,不复制任何第三方代码。

## 现状与差距

| 能力 | SVFI | ALHPro 现在 | 差距来源 |
|---|---|---|---|
| 任意 t 插帧 | PyTorch RIFE/GMFSS(接口支持任意 t) | 仅均匀整数倍(-n/-s) | **引擎接口限制** |
| 时间轴自由(慢段密/快段疏) | 有(任意 t 的 TMapper 网格) | 无(均匀铺) | 上一条 |
| 去重节拍(去除一拍二/与三) | AVFDU 式 | **已有(对齐)** | — |
| 转场保护 | SSIM<0.3 → t=0 复用 | **已有(对齐)** | — |

## 自研核心:二分级联任意 t

RIFE ncnn 引擎的一次调用只能插 **t=0.5**。任意 t 用二分递归逼近:

```
ArbitraryFrame(A, B, φ):
  if φ == 0.5:      return RIFE(A, B)                 # 一次 0.5
  M = RIFE(A, B)                                     # 中点
  if φ < 0.5:       return ArbitraryFrame(A, M, φ*2)
  else:             return ArbitraryFrame(M, B, φ*2-1)
```

- 精度:递归深度 d → 位置量化到 1/2^d;d=4 时 1/16 帧精度,视觉无差;
- **批量优化(关键,把开销压到一层一次引擎调用)**:同一帧对的一组需求 t 构成一棵二叉子树——**按深度分层**,每层把该层所有子节点对合并进一次**目录模式**插值(引擎对"输入序列相邻对"一次插完)。
  - 目录模式注意:必须把"独立对"用占位帧隔开,避免跨界误插(每层单独建目录,输入 = 该层对的首尾拼接 + 占位)。
  - 对于"每对需要 k 帧"的密度自适应场景,直接对每对跑 d=ceil(log2(k)) 层,输出 2^d 个中间帧 → 输出层(k 取所需) + 尾部 2^d-k 帧裁掉(或保留至补齐帧数)。

## 落地管线(节奏重采样,对标时空重采样)

```
关键帧(去重后序列 K, 原时间戳 t_k)
   ↓ 目标输出帧率 F(原帧率×倍率 或 指定)
每个输出时刻 t_j → 定位所在对 (K_i, K_{i+1}), φ = (t_j - t_i)/(t_{i+1} - t_i)
   ↓ 自研任意 t 插帧器(二分级联)
输出帧_j → CFR @ F
转场:对 (K_i,K_{i+1}) 若 SSIM(32×32)<阈值 → φ 归 0(复用 K_i)
```

- **效果**:慢速段时间被"拉平"地铺满(每对多插),快速段少插,输出帧率恒定=原×倍率,时长=原长;
- **与 SVFI 的差异(诚实)**:SVFI 的"多趟"(前进消重)是对未去重素材用中间帧层层接力;我们用"AVFDU 式节拍去重 + 任意 t"两条自主路径组合,效果目标一致。
- **成本**:二分 d 层 → 单对 2^d-1 次 0.5 插值调用;层内批处理优化后,实际引擎调用 = d 次(目录模式)。1080p GPU 实测基准后再定 d 与批大小。
