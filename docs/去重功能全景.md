# ALHPro 去重功能全景(2026-08-29 与 SVFI 三步语义对齐版)

> 使用方法:
> ① 勾选「启用去重」;② 选去重模型(智能/动漫/手动);③ 按模式调参;④ 可选「转场识别」;
> 所有模式最终输出 = 【原帧率×倍率(或指定目标帧率)】的完整时间轴,时长=原,尾部画面恒保留。

## 0. 整体流程(与 SVFI 三步语义对齐 —— 但全部自主实现,非抄袭)

```
① 去重(找"真画面"+记录每个在源时间轴的位置;只删重复/保持帧)
        ├─ 智能:自适应判据(真人/未知;自主实现:SAD+SSIM+镜头补偿,自动定阈值)
        ├─ 动漫:拍N 网格(一拍二/三/混合/半拍/四;自主实现:网格+相位对齐)
        └─ 手动-内容帧率:用户填真值(自主实现:任意间隔网格+相位对齐)
② 展开时间轴(把内容帧放回源位置,保持段=该停的停,运动段=渐变 —— "有规律去重"的两步走)
        ⬅ 全片一体(无分段);展开=硬链接零拷贝,随后标准补帧 ×倍率(每对=整数帧)
③ 输出 = 【原帧率×倍率】或【指定目标帧率(匹配屏幕 165 等)】· 时长=原 · 尾帧恒保留 · 变速=0
```

> 自主性声明:①-③的检测/网格/相位/补缺/尾帧保护全部为本项目实现(自研算法),
> 未复制 SVFI 任何代码;仅共用 RIFE 开源引擎(MIT,见 THIRD_PARTY_NOTICES)。

## 0b. 模式选择(决策树)

```
                       ┌── 智能检测(自动,零参数)──────── 逐帧"是否相同"删除(均衡差≤0.8)
启用去重 ──────────────├── 动漫模式(拍N 档位)────────── 按档位【网格抽帧】(与像素相似度无关)
                       └── 手动模式(专家)───────────── 4 个算法任选
                              ├─ 0 重复帧检测  → mpdecimate 高/低判线 + 比例(删"几乎相同"族)
                              ├─ 1 画面变化阈值 → scene 阈值(删"变化小"的)
                              ├─ 2 帧差+SSIM   → 快筛SAD + 精确SSIM + 保护(口型/微动防线)
                              └─ 3 内容帧率采样 → 按你填的真实内容帧率【网格抽帧】
```

## 1. 智能检测(推荐默认,通用)

流程(每段独立):
```
拆帧 → 转场切段(可选) → 段内逐相邻对:直方图均衡后差值 histDiff
   histDiff ≤ 0.8 → 这帧是"重复/保持帧" → 删
   histDiff > 0.8 → 有变化(运动/口型/微动)→ 永不删
→ 段首末帧强制保留;整段删除比例 >97% 视为"无重复"原样保留
```
- 优点:零参数、相位/变长保持免疫(不赌网格)、微动天然保留;
- 局限:重编码噪音重的保持帧(histDiff 0.8~3)可能漏删(此时改用动漫档)。
- 适用:真人/剪辑/变拍/未知素材。

## 2. 动漫模式(拍N档位)

流程:
```
选定档位 N → 按网格抽帧:保留 第 0, round(N), round(2N), ... 帧
   (拍二=2 → 隔1留1;拍三=3;混合=2.5 → 2/3 交替;半拍二=1.6;拍四=4)
→ 其余帧全部删除(与像素相似度无关,噪音免疫)
→ 输出=原帧率×倍率;时长=原
```
| 档位 | N | 24fps源内容 | 备注 |
|---|---|---|---|
| 去除一拍二 | 2 | 12fps | 最常用 |
| 去除一拍三 | 3 | 8fps | |
| 混合拍二+三 | 2.5 | ~9.6fps | 2/3 交替 |
| 半拍二 | 1.6 | 15fps | 轻量 |
| 去除一拍四 | 4 | 6fps | 慢镜头/抒情 |
- 局限:素材必须"固定拍N";相位偏移/变长保持会抽错 → 用智能档。
- 相位自动对齐(2026-08-28 实装):素材保持帧带相位偏移(拍型起点不在帧0)时,网格自动从真实相位起算;
  仅整拍(2/3/4)且高置信(事件≥3、间隔≈档位、相位集中≥60%)才移相,拿不准保持段首起算(绝不错抽)。
  开关:「相位自动对齐(网格模式)」,动漫/手动-内容帧率均显示。

## 3. 手动模式(4 个算法)

### 3.0 重复帧检测(mpdecimate)
| 参数 | 作用 | 默认/范围 |
|---|---|---|
| 变化判线 高 | hi=64×值:超过=必然保留(变化大) | 12 / 4~24 |
| 变化判线 低 | lo=64×值:低于=必删(几乎相同) | 5 / 2~10 |
| 重复比例 | frac:段内重复占比超此值才整段删 | 0.33 / 0.1~0.6 |
- 思路:ffmpeg 经典去重;"几乎相同的连续帧族"整体删除。

### 3.1 画面变化阈值(scene 滤镜)
| 参数 | 作用 |
|---|---|
| 变化阈值 | scene 评分超过=视为变化保留;低于=重复删 |
- 思路:整幅画面变化量 δ 直线阈值;低帧率/平移动画友好。

### 3.2 帧差+SSIM(精确)
| 参数 | 作用 |
|---|---|
| 快筛 SAD | 相邻帧差>此值直接保留(跳过 SSIM) |
| 相似阈值 | SSIM≥此值才认"重复" |
| (微动防线) | 局部动作保护:变化块占比超阈值保留(口型/眨眼防线) |
- 思路:两段式(快筛+精准),最"保守精确";默认开微动防护。
- 微动防线(2026-08-28 实装):UI 开关「微动防线(防口型/眨眼误删)」默认开,
  仅此算法显示;取消=只按整幅差异判定,删得更狠但口型/微动帧可能被误删。

### 3.3 内容帧率采样(手动已知节奏)
| 控件 | 作用 |
|---|---|
| 内容帧率 | 素材真实内容 fps(24fps 源拍二=12、拍三=8、拍四=6) |
| 保存按钮 | 立即存参数+提示 |
- 流程:间隔=源帧率÷内容帧率 → 网格抽帧(与动漫档同机制、可与任意 N 通用)。
- 徽标"内容≈Xfps"= 自动估计参考值(不覆盖手填)。
- 相位自动对齐:同上(手动填值与素材实际拍型相位不一致时自动对齐,高置信才生效)。

## 5. 已知边界(诚实清单)
1. 15% 下限保护:去重后帧数 < 原 15% → 报"去重过强"并弹确认框(点"仍要继续"跳过)。
   → 对象: 内容帧率填 <0.15×源fps(如 24fps 填 3fps=拍八)会被拦;确认后正常。
2. 智能档对"重编码噪音保持段(histDiff 0.8~3)"漏删 → 换动漫/手动网格。
3. 动漫/手动网格暂不做相位对齐(规划中;智能档天然免疫)。
4. 转场识别开关仅影响智能档切段;网格模式整段均匀,转场处保留采样帧(不误删)。
5. 输出帧率基准(真实时间轴/匀速):真实时间轴=原帧率×倍率(推荐);匀速=内容×倍率。
   两者时长都=原;唯一区别=平滑度的帧率高低。

## 7. 转场识别(全模式生效,2026-08-28 更新)
- 现状:ffmpeg scene 滤镜(直方图/帧差评分 >0.3 即切),用于:
  ①去重分段(智能档切段;动漫/手动网格【按段重启网格+段首保帧】→ 剪辑到新场景不会继承错拍);
  ②补帧转场处不插帧(SceneSlider 阈值)。
- 实测:转头(动画节奏)0 假转场;测试2(真人)16 处;对硬切识别良好。
- 已知弱项:淡入淡出/溶解(渐变转场)识别弱 → 补帧可能跨转场插值(鬼影)。
- 调研(2026-08-28,联网):
  * ffmpeg scene 滤镜见 [libavfilter/vf_scdet.c](https://patches.ffmpeg.org/doxygen/trunk/vf__scdet_8c_source.html)(阈值化帧差);
  * PySceneDetect(BSD)全家桶:[ThresholdDetector](https://www.scenedetect.com/docs/api/detectors.html)(亮度差,配 fade 识别)
    / ContentDetector(内容差,业界默认) / AdaptiveDetector(自适应 BNN) / HashDetector(哈希)——同类但更可调;
  * TransNetV2(CNN序列+剪辑预测,识别硬切+溶解,需模型+GPU推理)见 [论文](https://ar5iv.labs.arxiv.org/html/2008.04838) 与 [openshorts 参考实现](https://github.com/mutonby/openshorts/blob/main/scene_detection.py);
  * x265 直方图分镜方案见 [Histogram-Based Scene Change Detection for x265](https://www.mile-high.video/_files/ugd/3b5446_bc3f8cbcb8224d81b275623ddf30ccbd.pdf);
  * VLM(TransVLM 等)属前沿研究,本地跑不动,不适合。
- 结论/候选:保持 ffmpeg scene(默认);建议补"亮度趋势淡入淡出检测"(近零成本);
  进阶可选 TransNetV2(ONNX,需模型)。

## 6. 建议组合
| 素材 | 建议 |
|---|---|
| 真人/未知/剪辑 | 智能检测 + 转场识别 |
| 固定拍N 动漫(干净) | 动漫档位 或 智能(均可) |
| 固定拍N 动漫(重编码噪) | 动漫档位(网格免疫噪音) |
| 变长保持(AAA BBBBBBB CCCCC) | 智能检测 |
| 明确内容 fps(二次剪辑) | 手动-内容帧率采样 |
